# 이 프로젝트의 고정 대시보드 기준

확인일: 2026-10-30. 사용자가 현재 열린 클린뷰를 앞으로도 동일하게 구성하라고 직접 요청했습니다. 이 기준은 월요일 PBL 프로젝트와 이후 차수에 적용합니다.

- 기준 화면은 원래 5차 클린뷰의 배치와 8차의 현재 작업 연결입니다. 영상 선택·업로드·미리보기와 탐지 결과를 나란히 두고, 그 아래 학습 지표·후보별 그래프·작업 기록·로그를 둡니다.
- 배경색·카드·간격·색상·나눔고딕 Bold(700)를 유지합니다. 별도 요청 없이 단순 상태표나 다른 디자인으로 바꾸지 않습니다.
- 현재 조회 시각·마지막 작업 관측 시각·갱신 지연을 한국 시각(Asia/Seoul)으로 표시하고 8초마다 갱신합니다. 오래된 기록만으로 프로세스 종료를 단정하지 않습니다.
- 실제 다운로드·준비·GPU 학습·검증·최종 평가를 구분합니다. 없는 성능은 미측정으로 표시하고 다른 차수의 성능으로 대체하지 않습니다. 과거 기능 검사 영상과 현재 성능 평가를 구분합니다.
- 이후 차수는 같은 화면의 데이터 연결을 바꿉니다. 화면 조회나 서버 실행으로 학습을 새로 시작하지 않으며, 실행 중인 작업을 보존하고 중복 시작을 막습니다.
- 루프백 HTTP 앱의 인증·CSRF·Host·파일 경로 제한을 유지합니다. 로컬 접속 토큰은 Codex 사용 한도와 별개이고, 토큰과 세션은 공개하지 않습니다.

현재 배포 소스는 8차, 영상 처리 기반은 5차, 진행 중인 학습은 7차입니다. 화면 기준을 유지한다는 것은 모든 학습의 90% 성능 달성이나 과거 결과의 현재 성능 전환을 뜻하지 않습니다.
