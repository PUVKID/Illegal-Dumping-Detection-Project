# 8차 클린뷰 사용 안내

이 대시보드는 원래 5차 클린뷰의 배치와 영상 기능을 유지하고 7차 독립 학습 상태를 연결합니다. Python 3 환경에서 이 폴더의 `launcher.py --hidden --no-browser`를 실행합니다. 실행기와 화면 조회는 학습을 자동 시작하지 않습니다. 실행 후 로컬 `work/session.json`의 토큰 포함 URL로 접속합니다. 이 URL과 파일은 공개하지 않습니다. 학습이 실행 중이면 시작 버튼과 서버 요청 모두 중복 시작을 차단합니다.

현재 조회 시각과 마지막 작업 JSON 저장 시각은 모두 한국 시각(Asia/Seoul)입니다. 120초 넘게 갱신되지 않은 기록은 오래된 관측으로 표시합니다. 자료 다운로드·검증 과정에서는 저장 간격이 길 수 있으며, 이것만으로 실패나 프로세스 종료를 판단하지 않습니다. 실제 프로세스 생존은 별도 확인이 필요합니다.

정밀도·재현율·mAP50은 7차 최종 테스트가 생성된 경우에만 표시합니다. 두 후보 곡선은 각각 7차 실제 results.csv가 있을 때 표시하며 없으면 미측정입니다. 자료 준비와 GPU 학습을 구분합니다. 5차 과거 성능을 현재 학습 성능으로 표시하지 않습니다. 영상 탐지는 기존 5차 검증 모델을 계속 사용합니다.

원래 영상 업로드·목록·첫 프레임·영상 재생·탐지 결과 기능을 유지합니다. 업로드는 4GB 이하이며 토큰·요청 출처·CSRF를 검증합니다. 7차 로그는 등록 작업의 `round7/jobs/작업ID.log`만 최대 64KB 끝부분을 읽습니다. 잘린 여부와 원본·표시 바이트 수를 함께 표시합니다.

5차와 7차를 같은 상위 프로젝트 폴더에 보존해야 합니다. 8차는 해당 원본을 읽기 전용으로 불러오는 어댑터이며 단독 복사본으로 동작하지 않습니다. 데이터·가중치·실행 로그·토큰·개인 지침은 공개 배포 대상이 아닙니다. 학습 완료나 목표 P·R 각각 90% 달성은 보장하지 않습니다.
