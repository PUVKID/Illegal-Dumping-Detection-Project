# 8차 · 원래 클린뷰 복원과 7차 진행 상태 연결

[사용 안내](사용안내.md) · [로컬 공개용 변경 기록](변경기록.md) · [원래 5차 화면과 실제 전체 차이](docs/5차대비.diff) · [직전 7차 폴더와 공개 파일 비교](../docs/comparisons/7-to-8.md)

원래 5차 클린뷰의 영상 선택·미리보기·결과·학습 지표·곡선·로그 배치와 나눔고딕 Bold를 재사용합니다. 별도 8차 어댑터가 진행 중인 7차 준비·학습 상태를 읽고 한국 시각(Asia/Seoul)의 현재 조회·마지막 관측·지연을 표시합니다. 7차 학습 소스와 원본 기록은 수정하거나 재시작하지 않습니다. 현재 7차 최종 평가가 없으면 성능은 미측정입니다. 영상 탐지는 기존 5차 선택 모델을 사용하므로 현재 학습 성과와 구분합니다.

이것은 독립적인 새 학습 차수가 아니라 화면 복원 차수입니다. 같은 상위 폴더의 5차 영상 파이프라인과 7차 실행 자료가 필요합니다. 공개 저장소에는 원본 영상·데이터·모델·작업 로그·실행 토큰·세션을 포함하지 않습니다. 루프백 전용 HTTP 서버와 기존 토큰·CSRF·Host·경로 제한을 유지합니다. 페이지 조회는 학습을 시작하지 않습니다.

실행: Python으로 `launcher.py --hidden --no-browser`를 실행하고 로컬 `work/session.json`의 접속 URL을 사용합니다. 이 접속 값은 공개하지 않습니다. 의존 파일 해시는 현재 설치된 원본의 바이트 스냅샷입니다. Git 체크아웃의 줄끝 변환 때문에 5차 style.css 등에서 바이트 해시가 달라질 수 있으며, 이를 현재 해시로 자동 덮어쓰거나 검사를 끄지 않습니다. 기본 설치 환경은 Windows와 기존 D 드라이브 프로젝트입니다.

## 확인한 동작과 한계

- 전체23개 회귀 검사, 배포15파일·원본14개 해시 검사, JavaScript 구문 검사 및 별도 검증자의 HTTP·보안 검사가 통과했습니다.
- 실제 브라우저896×968에서 원래 두 영상 카드·학습 카드·한국 시각·최신7차 상태·미측정 성능·중복 학습 버튼 비활성화를 확인했습니다. 영상 선택 후1920×1080·3FPS 정보와 첫 프레임이 표시됐습니다.
- 과거 결과2개의 Docker→Windows 경로 누락으로 처음HTTP400/재생 불가를 발견했습니다. 기존 경로 변환을 복구하고 각실제결과Range206/원본64바이트, 브라우저메타데이터 readyState4·길이1초·error없음을 재확인했습니다. 이 과거1초클립은 기능 검사이며현재7차 성능을 증명하지 않습니다.
- 콘솔 오류·경고는 관측 범위에서0건입니다. 모바일 크기·4GB 실파일 업로드·새GPU영상추론·전체장기학습완료는 이번화면검증에서 실행하지 않았습니다.

[앞으로 유지할 대시보드 구성 기준](docs/대시보드기준.md)을 확정했습니다. 5차 화면 비교 패치는 설치 원본과 새 화면의 공통 코드 파일을 대상으로 원본 행 바이트를 보존합니다. 원본 CRLF의 CR이 패치에 포함되는 것은 비교 자료이며 제품 공백 오류와 구분합니다.
