# 마지막 실험의 원본 ID 복구와 재개

기존 실험의 데이터 수신은 완료됐으나 보존 pLitter 파일의 이름 규칙을 해석하지 못해 준비 단계에서 종료됐다. 공식 주석과 이전 저장 코드에 근거해 ID 대응을 복구하고 같은 후보와 학습 및 검증 계획을 이어간다. 추가 데이터와 후보 및 테스트 튜닝을 시작하지 않는다.

이전 원본 소스와 데이터 및 준비 계약과 실패 기록을 보존한다. 실효 실행 코드와 복구 근거를 별도 동결하고 기존 계약의 해시를 현재 코드로 조용히 대체하지 않는다. 과거 이미지는 재인코딩됐으므로 기존 해시와 새 공식 원본 해시를 혼동하지 않는다. 모호한 ID는 추정으로 채우지 않고 거부한다.

완료된 원자료 캐시와 보존 모델을 재사용하고 같은 자료를 다시 내려받지 않는다. 이전 failed 작업은 남기고 재개 시도와 연결한다. 동시에 하나의 준비·학습만 허용하며 다른 GPU 작업을 종료하지 않는다. 실제 데이터 준비와 GPU 학습 및 검증과 고정 테스트 단계를 구분해 기존 승인 대시보드로 표시한다.

실험 정상 종료와 세 고정 테스트 및 선택 가중치와 실효 코드·데이터 계약을 확인한 뒤 Word와 동일 원고 PDF 두 파일만 새 최종 하위 폴더에 생성한다. 이미 생성된 미완료 보고서는 보존한다. 실제 수치와 목표 미달도 그대로 쓰며 90%를 달성했다고 미리 주장하지 않는다. 후처리는 Codex나 언어 모델 반복 호출 없이 로컬에서 실행한다.

독립 검증에는 ID 매칭 회귀와 모호·미확인 거부 및 원본 불변과 캐시 재사용과 중복 기동·실패 상태·재개 작업 연결과 보고서 계약 대조를 포함한다. 실제 실행 전에 현재 검증 소스를 동결한다.
