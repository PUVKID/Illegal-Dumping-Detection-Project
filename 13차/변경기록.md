# 13차 변경 기록

## 추가

- 엄격한 이전 파일 명 해석과 공식 주석의 전수 ID 대응을 수행하는 legacy_ids.py를 추가했습니다.
- 원본 7차에서 허용된 네 AST 변화만 적용한 effective_prepare.py와 이를 검사하는 verify_sources.py를 추가했습니다.
- 별도 실효 계약과 준비 영수증, 같은 작업자의 잠금과 작업 계보, 최종 결과의 복구 바인딩을 관리하는 recovery.py를 추가했습니다.
- 보고서 연결과 관련 회귀 검사 및 설계·요구·사용 설명을 추가했습니다.
- 기존 원본 baseline과 실제 입력·캐시 해시를 source_contract에 보존했습니다.

## 보존과 비교

7·10·11·12차의 제품 소스는 수정하지 않습니다. 기존 준비 계약과 실패 기록을 보존하며, 실제 전체 파일 비교는 공개 반영 때 별도 변경 목록과 연결합니다. 파생 준비 소스의 정규화·분할·crop·검증·테스트 알고리즘은 승인된 네 AST 변환 외에 변경하지 않습니다. 전체 데이터·모델을 복제하지 않습니다.

## 검증 범위

파일 명과 공식 ID의 모호성·중복·잘못된 출처, 원본 불변과 추가 AST 변화, canonical 불일치와 캐시 손상, 작업 중복·기동 실패 및 최종 보고서의 복구 계약 불일치를 검사합니다. 실제 실행과 독립 검증 및 원격 반영 증거는 비공개 영수증으로 별도 기록하며 여기서 미리 통과나 90% 달성을 주장하지 않습니다.
