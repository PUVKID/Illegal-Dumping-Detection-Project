클린뷰 5차 · 독립 실행 안내

1. Docker Desktop과 GPU 작업 환경을 준비한 뒤 실행.bat을 더블클릭합니다.
   화면은 127.0.0.1에서만 열립니다. API 키나 Codex 토큰을 사용하지 않습니다.
   주소의 로컬 접속 토큰은 이 PC의 접근 보호용이며 Codex 한도·비용과 무관합니다.
   주소와 work/session.json을 다른 사람에게 공유하지 마세요.
2. 영상을 선택하거나 가져온 다음 탐지 시작을 누릅니다. 업로드는 최대 4GB입니다.
   브라우저에서 재생하지 못하는 코덱은 미리보기가 제한될 수 있습니다.
3. 추가 학습은 명시적으로 시작 버튼을 누를 때만 실행합니다.
   실행 중인 작업은 중복 시작하지 않으며 실패 원문을 화면에 표시합니다.
   화면을 닫아도 독립 학습 프로세스는 계속됩니다. PC·Docker 종료 시 계산은 멈춥니다.
4. 성능은 실제 평가값만 표시합니다. 정밀도·재현율 각각 90%는 목표입니다.
   객체 탐지 수치는 CCTV 투기 행동 판단의 정확도와 다릅니다.
5. 로그는 work 내부 허용 폴더에서 끝부분 최대 64KB를 읽습니다.
   원본 바이트 수·표시 바이트 수·생략 여부를 함께 표시합니다.

명령 실행: Python launcher.py --no-browser --port 0
숨김 독립 실행: Python launcher.py --hidden --no-browser
읽기 전용 루프백 확인: Python launcher.py --self-test
실행 중 주소와 프로세스 ID: work/session.json
정지: 해당 PID를 작업 관리자에서 종료합니다. 학습 프로세스는 별개입니다.

실행기는 프로젝트 runtime/python.exe, 그다음 현재 사용자 Codex 번들 Python을 찾습니다.
둘 다 없으면 소스 실행용 Python 런타임을 준비해야 합니다. Codex 앱 연결이나 로그인은 실행에 필요하지 않습니다.
CleanView5.exe는 Python 런타임을 내장합니다. EXE 옆 _internal·web·GPU 작업 소스·환경파일을 유지하세요.
EXE 의존성 확인: Python build_exe.py
프로젝트 전용 work/buildenv에서 EXE를 빌드했습니다. 실제 패키지 버전은 work/build-requirements.lock.txt에 기록합니다.
이전 차수와 원본은 보존하며 새 업로드·결과는 5차/work에 저장합니다.
