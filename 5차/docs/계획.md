# 복구 및 추가학습 계획
작성일: 2026-10-28, 사용자 직접 실행 요청. 구현 선택은 main의 판단이며 사용자 설계 승인으로 꾸미지 않습니다.
## 목표
D의 보존 자료로 탐지 앱을 실행하고 Codex 옆에서 대시보드를 제공합니다. Codex/API 토큰 없이 브라우저와 독립 프로세스로 계속 실행합니다. 새 데이터를 조사·확보하고 누출 없는 추가학습을 시작할 수 있게 합니다. 목표는 IoU .5에서 정밀도와 재현율 각각 .90 이상입니다. 성공을 보장하거나 미달 값을 숨기지 않습니다.
## 선택
기존 Docker 이미지·보존 모델과 Python 표준 HTTP 대시보드를 재사용합니다. 유료 클라우드/API 의존은 추가하지 않습니다. Docker 디스크 전체 교체보다 보존 폴더 바인드마운트와 별도 컨테이너로 한정 복구합니다. 이전 앱은 보존하고 신버전에 학습상태·로그·성능을 추가합니다.
## 구현
1. 기존 이미지 CUDA/Ultralytics/모델·GPU를 확인하고 2026-2 복구 또는 작업 전용 컨테이너를 생성합니다. 임의 디스크 재연결·삭제는 금지합니다.
2. dashboard.py와 launcher.py: 로컬 loopback, 토큰 인증, 업로드·미리보기·탐지·작업로그. 학습 시작은 중복 잠금과 독립 프로세스를 쓰고 결과를 work에 보존합니다. 앱 종료가 학습을 종료하지 않도록 합니다.
3. prepare_training.py와 train_pipeline.py: 출처 manifest, 해시·이미지 유효성·레이블 검사, train/val/test 분리, val 전용 선택, test 최종평가. 다운로드 실패와 용량 부족을 숨기지 않습니다. 기존 데이터와 신규 데이터를 섞되 중복·근접 중복은 holdout 우선 제외합니다.
4. 실행기와 사용안내, 필요 시 EXE. 재실행 시 완료학습을 자동 재시작하지 않습니다. 중단 checkpoint 재개를 지원합니다.
5. tests: 무인증·경로탈출·중복학습·없는파일·잘못된입력·실제상태를 검사합니다. 실제 Docker GPU·한프레임 탐지와 브라우저 핵심화면을 확인합니다. 별도 verifier가 최종 검사합니다.
## 보존 및 한계
기존 150장 test는 과거에 이미 평가된 historical benchmark로 표시합니다. 신규 미사용 holdout이 확보되면 별도로 보고합니다. CCTV 투기 행동 정확도는 객체검출 수치와 구분합니다. PC/Docker가 꺼지면 계산이 멈추며 재개가 필요합니다. Codex 토큰 소진과 PC 실행은 별개입니다.
