# 5차 데이터와 평가

확인일: 2026-10-28. 목표는 IoU 0.5에서 정밀도·재현율 각각 90% 이상입니다. 목표 달성은 보장하지 않습니다.

## 보존과 출처

기존 TACO 학습 1,200장·검증 150장·테스트 150장의 이미지와 라벨을 읽기 전용으로 재사용합니다. `reference_holdout_sha256.json`과 `original_holdout_sha256.json`의 과거 해시를 먼저 대조합니다. 현재 파일로 원본 기준을 바꾸지 않습니다. 원본 라벨과 데이터는 복사·덮어쓰기하지 않습니다.

추가 자료는 [공식 pLitterStreet](https://zenodo.org/records/8288500)에서 최대 4,000개를 준비합니다. [공식 SALSA](https://github.com/alinacherkas/salsa)의 보존 COCO 주석도 조사했으나 비TACO 1,244장은 모두 license=0(ODbL 표기)이고 CC BY 4.0인 license=1 신규 사진은 0개입니다. 이미지 권리를 CC BY로 대체하지 않으므로 이번 SALSA 추가 사용은 0개입니다. SALSA 주석은 ODbL이고 도구는 Apache 2.0이며 이미지 권리는 개별 필드를 따릅니다. 분류 전용 사진은 포함하지 않습니다. pLitterStreet의 trash bin 클래스는 제외하고 실제 쓰레기 상자만 단일 trash 클래스로 변환합니다. pLitterStreet 공식 API의 권리는 CC BY 4.0입니다. `sources.json`과 실제 데이터 manifest에 출처·URL·권리·해시를 남깁니다.

[RoLID-11K](https://github.com/xq141839/RoLID-11K)는 새 후보입니다. 공식 Google Drive 폴더는 HTTP 200과 공개 제목을 실제 확인했지만 데이터 파일은 받지 않았습니다. 공식 저장소는 Apache 2.0이지만 Google Drive 내부 데이터 권리는 미확인하여 사용하지 않습니다. 이 상태를 다운로드·사용 완료로 표현하지 않습니다.

## 데이터 안전과 재개

전송은 요청별 40초 제한, 실패 포함 누적 20GiB 상한입니다. 누적 전송량은 `work/training/download_ledger.json`에 남아 재시작으로 초기화되지 않습니다. ZIP 전체를 받지 않고 중앙 디렉터리와 선택 이미지 범위만 읽으며 응답 범위·크기·압축 크기·CRC를 검사합니다. 일반 다운로드는 ETag가 일치할 때만 부분 파일을 재개합니다. 실패는 `download_errors.jsonl`에 기록하며 성공으로 숨기지 않습니다.

이미지는 끝까지 해독하고 COCO 크기·유한 좌표·양수 면적을 확인합니다. 부분적으로 경계를 벗어난 COCO 상자는 실제 경계로 자르며, 이미지와 겹치지 않는 상자는 거부합니다. 학습 입력은 고정 holdout과 정확 SHA256 및 64비트 차분 이미지 해시의 해밍 거리 4 이하를 비교해 배제합니다. 이 근접 기준이 모든 유사 사진을 찾아낸다는 보장은 없습니다. 새 독립 테스트를 만들 때 필요한 영상 그룹 함수는 같은 GoPro 녹화의 장과 물체 종류별 하위 폴더를 통합합니다.

현재 추가 출처는 기존 3차 학습에 이미 사용됐습니다. 따라서 추가 이미지는 학습에만 사용하고 새 독립 테스트는 만들지 않습니다. 기존 테스트 150장은 **과거에 이미 평가된 historical benchmark**입니다. 미사용 외부 테스트의 성능이라고 표시하지 않습니다.

검사·중복 배제 후 실제 남은 수만 `data_manifest.json`에 고정합니다. manifest가 있으면 이미지·라벨 해시를 대조해 재사용하며 현재 파일에 맞춰 교체하지 않습니다. 다운로드·검사 단계와 카운트·전송량은 `status.json`으로 원자 저장해 대시보드가 읽습니다.

과거 `sources/additional_manifest.json`의 pLitterStreet 레코드에서 `plitter_<COCO ID>` 또는 `street_<COCO ID>`를 대조합니다. `counts.restored`는 그 명세에 있던 ID를 복원한 수이고 `counts.new_identity`는 그 명세에 없던 원본 ID 수입니다. 과거 재저장 JPEG와 원본의 해시가 다르다는 사실만으로 새 사진이라고 하지 않습니다. 새 ID도 과거 사용 영상·장소와 다를 수 있다는 뜻은 아니며, 미사용 독립 테스트라고 주장하지 않습니다. 과거 ID를 해석하지 못하면 새 자료로 추정하지 않고 오류로 중단합니다.

## 추가 학습과 비교

큰 YOLO26x, 1536 입력, 네 단계의 과거 실험에서 목표에 미달했습니다. 5차는 보존 YOLO26l-P2 집중 학습 가중치에서 작은 물체 후보 한 개를 미세 조정합니다. 입력 1280, batch 2, seed 20261028, 최대 180 epoch, patience 35, AdamW를 사용합니다. mosaic·scale 확대 증강은 학습에만 적용합니다. 원본 검증·테스트에는 증강을 적용하지 않습니다. 메모리 부족을 성공으로 숨기거나 CPU 바퀴로 교체하지 않습니다.

checkpoint는 데이터 manifest와 초기 모델·파이프라인 소스 해시·학습 조건이 같고 사용자가 재개를 명시한 경우에만 재개합니다. checkpoint가 있는데 재개를 선택하지 않으면 오류로 중단합니다. 완료 학습은 다시 시작하지 않습니다. 작업 프로세스와 로그는 부모 GPU worker가 소유하고 `train_pipeline.run(job, notify=callback, resume=False)`를 호출합니다. 이 구현은 장기 학습을 자체 시작하지 않습니다.

같은 고정 validation 150장에서 기존 선택 ensemble, 기존 단일 l-P2, 새 l-P2를 동일 입력 1280·전체 화면·NMS IoU 0.5로 비교합니다. 선택 순서는 min(P,R), F1, AP50이며 동점이면 먼저 등록한 기존 모델을 유지합니다. 모델마다 고정 임계값 후보를 validation에서만 비교합니다. 개선이 없으면 기존 모델을 유지합니다.

선택 결과에는 `imgsz=1280`도 저장하며 운영 추론은 같은 입력 크기를 사용합니다. baseline이 이번 검증에서 다시 선택된 경우에도 이 입력 크기를 기록합니다.

선택과 테스트 계약을 동결한 뒤 선택 모델 하나를 기존 테스트에서 평가합니다. 예측은 이미지별 원자 저장하여 중단 후 이미 평가한 이미지를 재사용합니다. 테스트 성능으로 선택·임계값을 다시 조정하지 않습니다. `final.json`을 저장한 완료 실험은 자동 재학습하지 않습니다.

AP는 신뢰도 순 단일 클래스 일대일 IoU 매칭과 101점 보간을 사용하고 AP50 및 IoU 0.50~0.95 평균을 기록합니다. 과거 Ultralytics 평가기·1536 입력과 조건이 다르므로 과거 보고서 수치와 직접 동일 조건 비교로 주장하지 않습니다. 이번 후보 세 개 사이의 비교는 같은 구현과 입력을 사용합니다. CCTV 투기 행동 정확도는 객체 탐지 지표와 별개입니다.
