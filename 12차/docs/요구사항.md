# 마지막 실험의 완료 후 보고서 생성

이미 진행 중인 지정 실험의 두 후보 학습과 검증 및 고정 테스트를 마지막으로 수행한다. 기존 데이터와 모델 및 계약과 실행 중인 프로세스를 보존하고 추가 데이터나 후보 실험을 시작하지 않는다. 보고서는 저자의 프로젝트 수행 관점으로 서술하되 확인되지 않은 개인 수행이나 성능을 만들지 않는다.

지정 작업의 정상 완료와 최종 결과 및 세 테스트와 선택 가중치 해시가 일치할 때 한 번만 Word 문서와 해당 Word에서 변환한 동일 내용의 PDF 두 파일만 생성한다. 표와 그래프는 두 문서 안에 포함하며 CSV와 PNG 및 렌더링 검증 자료는 내부 작업 폴더에만 보존한다. 실패 및 중단은 완료로 취급하지 않으며 실제 상태와 미측정 항목을 명시한다. 기록된 동결 실험을 다시 학습하거나 테스트 임계값을 조정하지 않는다.

본문은 개발 내용과 데이터 출처 및 권리와 전처리와 학습 및 검증 선택과 최종 성능 및 한계를 구체적으로 다룬다. 정밀도와 재현율 각각 90퍼센트 목표 달성 여부는 실제 결과로 판정한다. 자체 AP는 공식 COCO API와 구분하며 기존 평가와 조건이 다르면 동일 조건 개선율을 만들지 않는다. CCTV 투기 행동의 정답이 없으면 행동 정확도를 계산했다고 쓰지 않는다.

보고서와 작은 표 및 그림만 새 최종 하위 폴더에 저장하고 원본이나 모델을 중복 복사하지 않는다. 나눔고딕 Bold를 사용하며 기존 결과를 덮어쓰지 않는다. Word는 제공된 문서 도구로 렌더링해 현재 제어 사례의 모든 페이지를 시각 검사하고 실제 종료 후에도 렌더링 및 정합성 검사를 수행한다. 미래의 인간 시각 검토를 이미 수행한 것으로 표현하지 않는다. 로컬 완료 후 처리기는 Codex나 언어 모델의 반복 호출 없이 실행한다.
