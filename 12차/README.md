# 마지막 실험의 Word와 PDF 보고서

이미 진행 중인 지정 실험 하나가 끝나면 동결된 결과를 대조하고 작성자의 관점으로 최종 보고서를 만든다. 두 후보 학습과 검증 선택 및 세 고정 테스트는 기존 실험의 범위이다. 이 도구는 학습을 시작하거나 재개하지 않으며 데이터를 다운로드하지 않는다.

최종 납품은 같은 원고의 **DOCX와 PDF 두 개**이다. 그래프와 CSV 및 페이지 렌더와 검증 영수증은 비공개 지원 자료로 보관한다. 데이터와 모델은 복사하지 않고 위치와 SHA-256만 기록한다. 실험이 실패하거나 중단되면 성능을 채우지 않은 미완료 보고서로 구분한다.

보고서는 개발 알고리즘과 자료 출처 및 분할과 전처리와 실제 epoch 기록과 검증 비교 및 선택 조건과 고정 테스트의 P/R/F1·자체 AP·TP/FP/FN 및 작은 객체 성능을 다룬다. TN은 객체 탐지에서 정의하지 않는다. 정밀도와 재현율 각각 90% 목표는 별도로 판정한다. 과거 TACO 테스트를 새로운 독립 평가라고 부르지 않고 CCTV 투기 행동 정확도를 만들지 않는다.

운영 설정은 비공개 `work`에 둔다. `docs/계획서식.json`을 참고하여 지정 작업과 저자 및 새 출력 위치를 설정한다. `watcher.py --plan 비공개계획.json`은 60초마다 해당 작업만 안전 공유 읽기로 확인한다. 동일 작업 잠금과 완료 영수증으로 중복 생성을 막으며 기존 출력은 덮어쓰지 않는다. 검증한 운영 계획으로 가동한다.

Word는 공식 문서 도구로 렌더한다. 현재 허용된 렌더 설정이 없으면 `blocked_renderer`로 중단하고 최종 납품을 만들지 않는다. 초안 저장이나 자동 렌더가 미래의 인간 시각 검토를 뜻하지 않는다. 공개 소스에는 실제 작업 식별자와 저자 설정 및 개인 경로와 인증값을 포함하지 않는다.

검사는 `python -B -X utf8 -m unittest discover -s tests -v`와 `python -B -X utf8 verify_sources.py`이다. 실제 환경에서 확인한 Python 실행 파일을 사용한다. 가상 제어 사례는 실제 성능으로 인용할 수 없다.
