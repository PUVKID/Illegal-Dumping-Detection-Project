# 마지막 실험 보고서 도구의 변경 기록

진행 중인 한 실험을 마지막으로 마무리하고 저자의 관점으로 개발과 결과를 설명하는 Word 및 같은 원고 PDF 보고서를 만들기 위한 새 후처리 도구이다. 학습과 다운로드 및 평가의 기존 코드는 수정하지 않는다.

## 추가한 파일

- report_core.py: 지정 작업 판정, 원본·manifest·선택 가중치 해시와 세 테스트 및 평가 계약 대조, 고정 예측 기반 PR/F1 분석, 실제 epoch CSV 읽기.
- report_outputs.py: 작성자 관점 본문과 실제 표 및 그래프를 포함한 Word 초안, 명시적으로 허용된 공식 렌더 설정을 이용한 같은 원고 PDF 변환. CSV 및 PNG는 비공개 지원 자료로만 저장.
- watcher.py: 60초 간격 지정 작업 읽기, 10차 안전 공유 읽기 사용, 단일 잠금과 완료 영수증, 기존 결과 덮어쓰기 거부, 학습 실행 기능 없음.
- report_sections.json: 별도 문서 담당자가 동결한 고정 설명. 실제 수치는 생성기가 검증 뒤 삽입하며 이 파일의 작성과 동결 소유를 보존.
- verify_sources.py 및 tests의 다섯 파일: 엄격 UTF-8·구문·공개 파일·7차 원본 불변·고정 의존성 검사, 합성 자료의 완료·실패·오염·순서·중복 생성 회귀, 시제품 문서 작성 도구.
- README.md, ROUTING-LESSONS.md 및 docs의 설계·요구사항·비공개 계획 서식·렌더 설정 서식·원본 계약·결과 해시 스키마.

## 이전 차수와의 차이

11차는 기존 자료 수신을 복구하고 7차 준비와 학습에 연결하는 실행기이다. 12차는 자료를 수신하거나 학습을 실행하지 않으며 기존 작업의 종료 후 문서만 작성한다. 기존 7차와 10차 및 11차 제품 파일은 변경하지 않는다. 새 차수의 전체 공개 파일은 verify_sources.py의 PUBLIC_FILES에 명시한다.

최초 요구의 HTML·Markdown·CSV·PNG 납품은 사용자의 최종 Word·PDF 지정에 따라 구현하지 않았다. 최종 폴더에는 정확히 두 문서만 저장하며 분석 및 렌더 지원 파일은 비공개 폴더에 둔다.

## 검증과 제한

수리 1에서는 JSON 키 저장 순서와 주목표 판정의 불필요한 의존을 명시적 historical_taco 참조로 고쳤다. 평가 입력 크기·confidence 하한·NMS·최대 탐지 수·평가기·프로토콜도 원래 계약과 대조한다. 38개 단위 검사가 통과했으며 통제 RED 및 명령 경로 오류는 비공개 evidence에 보존한다. 원본 불변·소스 검사는 최종 동결 시 별도 실행한다.

공개 기술 교훈은 결과 정합성과 문서 변환의 확인 사항만 남겼으며 내부 운영 조율과 비공개 정보는 제외했다. 작성자 설정 회귀에는 가상의 식별자만 사용한다. 시제품 렌더에서 확인한 기본 제목 장식선을 제거하고 명시 글꼴과 충돌하는 테마 글꼴 속성을 정리했으며 표의 실제 열 격자를 지정한 폭과 일치시켰다. 기존 시제품 및 9쪽 렌더는 내부 이력으로 보존하고 새 시제품을 별도로 검토한다.

완료 영수증 재사용 시 실제 출력 두 파일과 납품 위치 및 크기·SHA-256을 확인한다. 정상 완료는 현재 작업 결과와 최종 입력 해시까지 다시 묶는다. 보고서 누락과 변경 및 최종 입력 불일치가 있으면 완료를 반환하지 않고 오류를 기록하며 기존 결과를 보존한다.

최종 수리 묶음은 44개 단위 검사와 공개 19개 파일의 엄격 UTF-8·구문 및 원본 해시 검사를 통과했다. 새 가상 결과 시제품의 Word에서 동일 원고 PDF와 8쪽 페이지 이미지를 생성하고 모든 페이지의 본문·표·차트·페이지 번호를 직접 확인했다. 자동 생성기가 사용하는 렌더 함수에서도 같은 시제품의 8쪽 변환을 확인했다. 이는 제어 사례의 문서 검사이며 실제 실험 성능이나 미래 결과 문서의 인간 검토를 뜻하지 않는다.

구체 Word 시제품은 합성 결과임을 표시한 편집 초안이다. 허용된 LibreOffice 렌더 경로가 확인되기 전에는 최종 DOCX/PDF 납품 또는 전체 페이지 시각 품질 통과를 주장하지 않는다. 선택 checkpoint의 epoch는 원래 결과에 명시되지 않아 미확인으로 보고하며 완료 epoch를 대신 쓰지 않는다. 실제 실험 완료와 정밀도·재현율 90% 달성을 미리 주장하지 않는다.

## 공개 제외

실제 작업 식별자와 저자 운영 설정, 프로세스 정보와 접속·인증값, 원자료와 모델 및 가중치, 비공개 로그, 시제품과 내부 CSV·PNG·렌더·영수증은 공개 코드에서 제외한다. 실제 최종 보고서는 별도의 공개 범위 검토와 독립 검증 및 반영 확인을 거친다.
