# 9차 · 7차 자료 수신 재개

[변경 기록](변경기록.md) · [8차와 공개 파일 비교](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/docs/comparisons/8-to-9.md) · [7차 실험 코드](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/7차/README.md)

7차의 중단된 자료 수신을 기존 계약에 따라 재개한 운영 기록입니다. 새 학습 코드나 새 모델 차수가 아닙니다. 8차 클린뷰의 기존 화면과 실행 중인 세션을 사용합니다.

2026-10-30 자료 수신 도중 상태 파일의 원자적 교체가 권한 오류로 실패하여 작업이 중단됐습니다. 당시 부분 수신 파일은 8,758,012,844바이트였고 GPU 학습은 시작되지 않았으며 체크포인트도 없었습니다.

2026-11-02 상태 파일 교체 검사를 통과하고 사용 가능한 저장 공간 336.87 GiB를 확인한 뒤 재개했습니다. 관측 시 작업은 진행 중이고 오류 상태는 없었으며, 부분 수신 파일이 8,762,207,148바이트까지 증가했습니다. 이는 해당 시점의 관측이며 전체 수신 완료를 뜻하지 않습니다.

기존 공식 MD5 확인, 전송 예산과 자료 분할 계약을 유지합니다. 자료가 준비되면 기존 파이프라인이 학습과 평가에 이어지도록 구성돼 있습니다. 정밀도·재현율 각각 90%는 목표이며 달성은 확인되지 않았습니다. 과거 테스트와 독립 평가의 구분은 [7차 실험 계약](../7차/docs/출처와실험계약.md)을 따릅니다.

데이터·모델·실행 상태·로그·인증정보와 개인 기록은 포함하지 않습니다. 이 차수의 공개 대상은 운영 재개 기록이며 논문 원고가 아닙니다.
