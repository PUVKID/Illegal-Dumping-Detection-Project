# 14차 DMF 적용 변경 기록

[다섯 읽기 수준](README.md) · [직전 13차](../13차/) · [사용법](docs/사용법.md)

기존 쓰레기 탐지 프로젝트의 문서 변경과 보존을 고정 DMF 무결성 라이브러리에 연결했습니다. 13차의 원본 준비 복구기와 학습 계보는 수정하지 않았습니다. 이 문서는 이번 연결 코드 담당 범위의 추가 파일과 직접 실행 결과를 기록합니다. 보고서·전체 공개 파일 비교·원격 반영·독립 검증은 별도 최종 기록을 따릅니다.

| 종류 | 파일 | 구체 변경 |
| --- | --- | --- |
| 추가 | dmf_adapter.py | 고정20파일 검사, 모듈·버전·감사·병합·롤백, 새 출력 및 재검증 |
| 추가 | 실행검증.py | 생성·읽기 전용 재검증 CLI, 경로·거부 오류 종료 |
| 추가 | configs/입력명세.json | 실제 입력 네 파일과 변경 등급 명시 |
| 추가 | configs/DMF고정해시.json | 원문 없는 커밋·트리·20파일 바이트 근거 |
| 추가 | tests/test_dmf_adapter.py | 실제 원본 통합과 거부·변조 회귀 10개 |
| 추가 | README.md·docs/사용법.md·docs/적용범위.md | 다섯 수준·재현·실제 한계 설명 |
| 추가 | 실행결과의 JSON 6개 | 버전3·감사3·입력SHA·실제검사14·실행봉인 |

| 검사 | 실제 결과 | 해석 |
| --- | --- | --- |
| 최초 제어 TDD | 미구현 진입점 1개 실패 | 구현 전 기대 동작 확인, 자연 오류 아님 |
| 어댑터 unittest | 10/10 통과 | 링크 속성 모사 포함, 실제 링크 생성 없음 |
| 원본 unittest | 18/18 통과 | 고정 원본을 실제 임포트하여 실행 |
| 실제 입력 실행 | 14/14 로컬 검사 통과 | G1~G9 전체 PASS 아님 |
| UTF-8·AST | 소스 3파일 통과 | 완전 무오류·타입 검사 보증 아님 |

명령의 작업 위치는 프로젝트 루트이며 Python에 `-B -X utf8`을 지정했습니다. 실행 명령은 [사용법](docs/사용법.md)에 보존합니다. 직접 실행은 모두 종료 코드 0이고 최초 제어 TDD는 기대한 종료 코드 1입니다. Ruff·mypy·Pyright는 설치되지 않아 해당 정적 검사는 수행하지 않았습니다.

원본 입력은 전후 SHA-256이 일치했습니다. 정상 개정은 사본에 예시 문구를 추가한 v2이고 v3은 부모 v2에 연결해 v1 내용을 복원한 새 버전입니다. 불변 변경·대폭 제한 변경·소급 변조·감사 변조·병합 충돌은 원본을 건드리지 않는 통제 사례입니다. 제한 변경의 R2 하한은 확인했지만 변경률 20% 계산·승인 정책 자동 집행은 API 범위 밖입니다.

공개용 어댑터에는 라이선스가 확인되지 않은 upstream 코드를 복제하지 않습니다. 로컬 원본·취득 내부 로그·개인 지침·의료 또는 CCTV 원영상·인증값은 공개 파일에 포함하지 않습니다. 독립 verifier 영수증을 구현자가 자체 발급하지 않습니다.

- 보고서 Markdown 공개 사본의 그림 상대 경로만 공개 폴더에 맞추었습니다. 실제 모델 학습이나 공식 배포 승인을 수행한 것은 아닙니다.
