# 실행과 결과 확인

[다섯 읽기 수준](../README.md) · [적용 범위](적용범위.md)

프로젝트 루트에서 Python 3.10 이상으로 실행합니다.

외부 패키지는 설치하지 않습니다.

DMF는 [고정 커밋](https://github.com/leecursion/DMF/tree/cf550e3b2ceb0946ba89f64e43b7d6c2f5164383)의 원본 20 파일을 `14차/work/DMF원본`에 준비해야 합니다.

폴더 이름을 바꾸면 `--dmf-root`에 실제 위치를 지정합니다.

원문 코드는 이 공개용 어댑터에 포함하지 않습니다.

원본 저장소의 다운로드와 이용 조건은 사용 전에 확인해야 합니다.

| 준비물 | 조건 | 역할 |
| --- | --- | --- |
| Python | 3.10 이상, 표준 라이브러리 | 실행·unittest |
| DMF 원본 | 고정 커밋의 정확한 20 파일 | 실제 API 임 포트 |
| 입력 자료 | 자료 폴더의 지정 네 문서 | 원본 바이트 보존 |
| 출력 경로 | 아직 없는 새 디렉터리 | 이전 결과 보호 |

```powershell
python -B -X utf8 "14차/실행검증.py" --dmf-root "14차/work/DMF원본" --input-dir "14차/자료" --output-dir "14차/새실행결과"
```

출력 디렉터리를 새로 만들고 아래 파일을 생성합니다. 첫 보존 실행의 `실행결과`는 변경하지 않으며 반복 실행은 다른 새 디렉터리를 지정합니다. 출력은 입력·원본·설정·검사 소스 위치와 겹칠 수 없습니다.

| 파일 | 내용 | 확인 방법 |
| --- | --- | --- |
| 버전기록.json | v1·개정 v2·복원 v3 | v3 부모=v2, v3 manifest=v1 |
| 감사 기록.json | 버전별 예시 행위 3개와 head | 버전 해시와 target 연결 |
| 입력해시.json | 선택 명세와 원본 바이트 SHA | 원본 네 파일과 대조 |
| 모듈내용.json | 원본과 예시 개정본의 실제 텍스트 | UTF-8 재인코딩 SHA 대조 |
| 검증 결과.json | 로컬 검사 14개·원본 임 포트 근거·한계 | summary·checks·upstream |
| 실행봉인.json | 출력·현재 소스·정책·감사 head 결합 | 별도 SHA 보존 권장 |

기존 결과를 쓰지 않고 다시 검증하려면 다음 명령을 사용합니다.

```powershell
python -B -X utf8 "14차/실행검증.py" --dmf-root "14차/work/DMF원본" --input-dir "14차/자료" --output-dir "14차/새실행결과" --verify-only
```

별도로 보존한 실행 봉인 SHA가 있으면 `--expected-seal-sha256`에 그 64 자리 값을 추가할 수 있습니다. 코드·정책·검사 또는 입력이 바뀌면 과거 결과의 재검증은 거부됩니다. 봉인 자체를 별도 대조하지 않으면 출력과 봉인을 함께 다시 쓰는 행위를 로컬 해시만으로 판별하지 못합니다.

```powershell
python -B -X utf8 -m unittest discover -s "14차/tests" -v
```

성공 종료 코드는 0입니다.

경로·원본·해 시 불일치 등 거부는 1로 종료하고 오류를 표시합니다.

명령 인자 구문 오류는 argparse가 2로 종료합니다.

기존 폴더 거부는 결과를 삭제해 해결하지 말고 새 출력 경로로 재현합니다.

상대 경로 탈출·중복·링크·정책과 다른 선택은 거부합니다.

재분석 경로의 회귀 검사는 링크를 실제 생성하지 않고 속성을 모사했습니다.

로컬 자동 검사의 성공과 사람의 사실 확인·교수 승인·운영 승인·G1~G9 승격은 서로 다른 상태입니다. 이 실행은 `Shadow / local_validation_only`로 표시하며 사람 승인값을 생성하지 않습니다.
