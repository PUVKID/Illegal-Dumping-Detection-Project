# ICT 안전 프로젝트 DMF 적용 설계

사용자가 지정한 leecursion/DMF를 기존 CCTV 불법 쓰레기 탐지 프로젝트에 적용한다. 별도 제출 양식 없이 Word와 PDF 보고서 및 실제 실행과 검증 자료를 함께 만드는 구성을 사용자가 확인했다.

| 항목 | 적용 방식 | 확인 기준 |
| --- | --- | --- |
| 원본 보존 | 기존 차수는 읽기만하고 14차에 신규 저장 | 기존 입력의 전후 SHA 일 치 |
| 문서 분해 | 목적과 안전 경계 및 현재 결과를 별도 모듈로 표현 | 모듈별 해시와 순서 기록 |
| 변경 제한 | 평가 원칙과 개인정보 경계를 불변 모듈로 지정 | 변조 사례는 거부 |
| 변경 추적 | 초안과 개정안 및 되돌리기를 새 버전으로 기록 | 부모 버전과 감사 연결 확인 |
| 공식 배포 | 로컬 Shadow 결과까지만 생성 | 사람의 승인과 운영 게이트는 미수행으로 표시 |
| 제출물 | DMF 적용 보고서 Word와 동일 원고 PDF 및 실행 자료 | 독립 실행과 모든 문서 페이지 검토 |

실제 Python 무결성 라이브러리를 사용한다.

API 서버·PostgreSQL·OIDC·KMS·외부 타임 스탬프를 구현하거나 운영한 것으로 쓰지 않는다.

학습을 재개하거나 기존 모델 성능을 개선하는 작업이 아니다.

원본 DMF에 배포 라이선스가 확인되지 않아 원문 코드는 비공개 로컬 참조로만 보존한다.

사용자 승인·교수 승인·보안 인증을 합성하거나 90퍼센트 성능 달성을 주장하지 않는다.

접근법은 전체 운영 서버 구축과 기존 라이브러리를 사용하는 로컬 검증을 비교했다. 수업 제출과 현재 제공 코드 범위에 맞는 로컬 검증을 이번 구현 선택으로 삼는다. 이 선택은 사용자가 별도 승인한 운영 서버 설계라는 뜻이 아니다.
