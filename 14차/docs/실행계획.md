# DMF 적용 실행 계획

목표는 기존 쓰레기 탐지 프로젝트의 사실과 안전 경계를 문서 모듈로 묶고 실제 DMF 라이브러리로 변경과 무결성을 확인하는 것이다.

구조는 기존 자료의 읽기 전용 스냅샷, 프로젝트 모듈, DMF 연결 코드, 실행 증거, Word와 PDF 보고서로 나눈다.

Python 표준 라이브러리와 고정 DMF 원본을 사용한다.

설계는 요구 사항과 설계.md를 따른다.

- [ ] 고정 커밋의 원본과 API 및 정책을 조사한다.
- [ ] 기존 프로젝트의 제한된 사실 입력을 동결하고 전후 해시를 기록한다.
- [ ] 연결 코드와 보호 항목 변경·제한값 초과·파일 변조·병합 충돌·롤백 검사를 구현한다.
- [ ] 실제 자료에 실행하여 버전·감사·검사 결과를 저장한다.
- [ ] 실제 결과로 표와 흐름도를 포함한 보고서를 작성하고 모든 페이지를 확인한다.
- [ ] 구현자와 다른 검토자가 재실행하고 공개 권한과 설명을 대조한다.
- [ ] 공개 가능한 코드와 차수 설명을 게시하고 두 게이트 및 원격 파일을 확인한다.

실패 시험은 기존 자료를 바꾸지 않는 임시 사본에서만 수행한다. 상대경로 탈출·심볼릭 링크·중복 모듈·서로 다른 승인 해시·없는 외부 라이브러리를 거부한다. 로컬 해시 검증은 사실의 진실성·신뢰된 타임스탬프·수학적 인증을 대신하지 않는다.
