# 적용 범위와 검증 한계

[다섯 읽기 수준](../README.md) · [사용법](사용법.md)

DMF의 문서 무결성 Python API를 CCTV 불법 쓰레기 탐지 프로젝트의 설명 자료 네 개에 적용했습니다. 관측 사실 JSON의 원래 소수 값과 줄 바꿈을 포함한 전체 바이트를 그대로 보존합니다. 운영 영상·가중치·개인정보·학습 프로세스는 입력 대상이 아닙니다.

| 분류 | 입력 | 변경 원칙 |
| --- | --- | --- |
| 가변 | 프로젝트개요.md | 사본 예시 개정 R1 |
| 불변 | 안전경계.md | 내용·등급·추가·제거 제약 |
| 가변 | 개발내용.md | 독립 병합 예시 대상 |
| 제한 | 관측사실.json | 등급 접촉 시 R2 하한 |

| 실제 사용 | 처리 | 추가 경계 |
| --- | --- | --- |
| ModuleRef·content_sha256 | 원본 바이트의 모듈 참조 | 중복 경로·ID 거부 |
| check_restrictions·risk_floor | 불변 위반·등급별 하한 | 승인 및 변경률 정책 미구현 |
| build_version·verify_version_chain | 새 버전과 직전 연결 | 저장 manifest·seal과 순번을 추가 대조 |
| three_way_merge | 다른 모듈 병합·동일 모듈 충돌 | 모듈 내부 텍스트 병합 아님 |
| AuditChain·verify_chain | 행 연결·내용 변조·꼬리 삭제 확인 | 빈체인·비영 head 추가 거부 |

**20% 초과 변경률 자동 집행은 구현되지 않았습니다.** 제한 모듈을 원문보다 큰 추가 바이트로 바꾼 합성 사본으로 API가 R2를 반환하는지 확인했습니다. 이 API는 변경 량 비율을 계산하지 않고 제한 등급이 건드려졌는지 판단합니다. 관측 수치를 실제 변경해 저장한 결과가 아니며 사람의 승인을 대신하지 않습니다.

| 검증 경계 | 수행한 확인 | 남은 범위 |
| --- | --- | --- |
| 고정 원본 | 20 파일 SHA·크기·Git blob, 실제 임포트 7 파일 SHA | 라이선스 부재, 원본 공개 재배포 안 함 |
| 실행 자료 | 14개 로컬 검사의 기대 동작 | G1~G9 전체 운영 게이트 아님 |
| 회귀 | 통합 검사 10개, upstream 검사 18개 | 실제 OS 링크 생성·제거 미시험 |
| 텍스트 | 소스 3 파일 엄격 UTF-8·AST | 정적 타입·Ruff 도구 미설치 |
| 저장 | 새 폴더·파일 배타 생성 | DB 트랜잭션·CAS 동시성·내구성 보장 아님 |
| 신뢰 | 로컬 해시와 보존한 봉인 SHA 대조 | 전자서명·KMS·WORM·외부 시간 앵커 없음 |

실행봉인은 정책과 현재 어댑터 및 검사 소스·입력·출력에 연결됩니다.

검증 뒤 이들이 바뀌면 과거 결과를 그대로 승인 근거로 쓰지 못하게 탐지합니다.

하지만 같은 권한으로 모든 기록과 소스·봉인을 함께 바꾸는 주체에 대한 인증 경계는 아닙니다.

원본 해시를 만족한 코드 임포트는 서버 보증 모델 신원이나 원격 실행 보증과도 다릅니다.

문서의 사실 확인은 입력 자료 출처와 기존 결과의 의미를 별도로 검토해야 합니다. 5차 보존 지표와 14차 문서 적용 검사를 구분하며 새 성능을 만들어 내지 않습니다.

상태가 Shadow 여도 실제 운영 트래픽과 병행 배포한 증거는 없습니다.

Official 승격·PostgreSQL/RLS·OIDC·서명·승인 정족수·소비자 계약·관찰 시간은 미구현 또는 미수행입니다.
