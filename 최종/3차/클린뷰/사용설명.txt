클린뷰 3차 — 새 학습 및 추가 데이터

실행: CleanView.exe 더블클릭. Docker Desktop 및 2026-2 컨테이너가 필요합니다.
영상 선택 → 탐지 실행 → 탐지 기록 순서로 사용합니다. 세부 설정은 접혀 있습니다.
모든 화면은 내장 나눔고딕 Bold를 사용합니다.

이번 작업
- YOLO26x와 작은 물체용 YOLO26l-P2를 추가 데이터로 새로 학습합니다.
- 각 모델은 혼합 데이터 학습(최대180epochs), 집중 미세 조정(최대60epochs)을 거칩니다.
- TACO 비공식 추가 사진, SALSA/OpenLitterMap, pLitterStreet를 학습에 사용합니다.
- 작은 물체 주변을 확대하는 학습 사진은 학습 분할에서만 만듭니다.
- 원본 해상도 사진을 복원하고 확대 구역의 잘린 중복 탐지를 줄입니다.
- 검증에서 모델/앙상블, 확대 분할 및 신뢰도를 선택합니다.
- 정밀도·재현율 각각90% 이상이 목표이며, 실제 달성 여부는 최종 테스트로 확인합니다.
- 기존 테스트150장의 사진 정체성과 정답은 유지합니다. 원본 해상도 평가이므로 이전 축소 입력과 직접 동일 조건 비교는 아닙니다.
- 최종 테스트 평가 후 추가 학습은 자동으로 하지 않습니다.

자료 위치: 바탕화면/월요일 PBL/3차
클린뷰: 실행파일·소스·폰트·라이선스
데이터: 원본과 추가 데이터, 학습용 확대 이미지
테스트영상: 기존28개 영상
출처: 이미지별 출처·라이선스·제외 내역
실험기록 / 평가원자료 / 보고서: 학습 완료 후 보관
_작업: 빌드 환경과 완료 처리 로그

학습 코드는 train_round3.py, 데이터 준비는 data_pipeline.py입니다.
추론·평가 공통 코드는 inference.py, 의심 장면의 시간·사람 이탈 규칙은 detector.py입니다.
최종 자료 저장은 finalize_round3.py, 종료 신호를 받는 로컬 처리기는 finish_on_exit.py입니다.
이 처리기는 주기적으로 진행 상태를 확인하지 않으며 Codex/API를 호출하지 않습니다.
파일 저장과 검증이 끝나면 PC에 완료 알림이 표시됩니다.

CCTV의 실제 투기 행동은 정답 라벨이 없어 정확도를 계산하지 않습니다.
기존물체 제외·정지 물체 지속·사람 이탈 규칙은 의심 장면을 기록하며 사람의 확인이 필요합니다.
