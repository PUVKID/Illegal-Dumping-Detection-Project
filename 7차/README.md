## 자료와 처리

공식 pLitterStreet 전체 원본, 새 PlastOPol 자료를 학습 준비에 사용하고 UAVVaste 전체는 새 출처 외부 테스트로만 보존합니다. 세 자료 모두 공식 Zenodo의 CC BY4.0을 확인했습니다. 변환·중복/근접그룹·분할 검사 뒤 실제 유효 원본 수를 동결하며 crop·반복 노출 수와 구분합니다. 출처·정확 URL·공식 크기와 MD5·주석 정의·한계는 [실험 계약](docs/출처와실험계약.md)에 있습니다.

원본 파일과 RGB JPEG 학습용 사본의 해시를 따로 기록합니다. 학습 후 자동 JPEG 재저장으로 원본 해시가 달라졌던5차 문제를 예방합니다. TACO·PlastOPol 노출 비율을 보호하고 작은 물체 crop은train에서만 만듭니다.

## 실행 조건

현재 운영 환경은 Windows D:/2026/월요일 PBL/7차, Docker컨테이너2026과 /workspace/2026 마운트, /opt/venvs/torch/bin/python입니다. 기존 모델·자료·5차 결과가 필요하고 이 저장소에는 모델·데이터·EXE·로그·인증정보·개인 지침을 포함하지 않습니다. 복제만으로 전체 실험이 재현된다고 보장하지 않습니다.

학습실행.bat은자료 준비와학습을독립프로세스로시작하고학습상태.bat은실제생존상태를조회합니다. 같은준비/학습을중복실행하지않고실패원문을보존합니다. 명시적재개에는원본·코드·모델·설정계약일치가필요합니다. Codex/API토큰을요구하지않지만PC와Docker는실행돼있어야합니다.
