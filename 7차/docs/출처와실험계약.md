# 자료 출처와 고정 평가 계약

작성일: 2026-10-30. 7차는 대규모 자료 추가라는 별도 사용자 요청이며 5차와 6차를 그대로 보존합니다. 5차의 20GiB 전송 계약을 수정하지 않습니다.

## 채택 자료와 권리

| 출처 | 공식 원본과 권리 근거 | 공식 규모 | 이번 용도 |
|---|---|---:|---|
| pLitterStreet | [Zenodo 8288500](https://zenodo.org/records/8288500), 공식 API CC-BY-4.0 | 13,064장, 전체 79,101개 주석 | 기존 출처를 전체 범위로 복원·확장, train 전용 |
| PlastOPol | [Zenodo 5829156](https://zenodo.org/records/5829156), 공식 API CC-BY-4.0, [연구기관 설명](https://research.wur.nl/en/datasets/plastopol-a-dataset-for-litter-detection/) | 2,418장, litter 상자 5,300개 | 공식 test 및 fold1 validation을 우선 보존, 나머지 train |
| UAVVaste | [공식 저장소](https://github.com/PUTvision/UAVVaste), [Zenodo 8214061](https://zenodo.org/records/8214061), 공식 데이터 API CC-BY-4.0 | 772장, 저장소 기준 3,718개 주석 | 전체를 새 출처 외부 테스트로 보존; train/val 사용 0장 |
| 보존 TACO | 기존 5차 불변 manifest 및 이미지별 출처 | train 1,196장, val/test 각150장 | 과거 train/val/test 분리 유지; 새 권리를 부여하거나 원본을 배포하지 않음 |

원문 API의 파일 크기·MD5·권리는 evidence/공식데이터출처.json에 보존되어 있습니다. pLitter의 images.zip은 13,728,630,001바이트, annotations.zip은 8,764,662바이트, PlastOPol ZIP은 7,709,841,780바이트, UAVVaste ZIP은 3,010,727,259바이트입니다. 전체 수신 뒤 공식 크기·MD5와 실제 SHA256을 모두 검사합니다. PlastOPol ZIP에는 images.zip과 plastopol-annotations_folds.zip이 들어 있으므로 중첩 ZIP도 CRC를 검증합니다. 이중 보관에 필요한 디스크 공간도 별도로 확인합니다.

RoLID-11K는 [공식 저장소](https://github.com/xq141839/RoLID-11K)의 Apache-2.0을 데이터 권리로 간주하지 않습니다. 데이터 라이선스 확인 전에는 수신·학습하지 않습니다. DroneWaste는 UAVVaste와 다른 자료이며 루블·석면지붕 등 클래스 의미가 달라 이번에는 채택하지 않습니다. 분류 전용 TrashNet/RealWaste 및 쓰레기통 탐지 자료를 litter 상자로 임의 변환하지 않습니다.

## 클래스와 정규화

단일 클래스 이름은 trash입니다. pLitterStreet의 1 litter, 2 pile, 3 face mask, 5 plastic bag, 6 bottle, 7 cup, 8 rope, 9 sachet, 10 straw를 trash로 대응하고 4 trash bin은 제외합니다. PlastOPol의 category1 Trash와 UAVVaste의 category0 rubbish를 각각 trash로 대응합니다. 명세에 없는 category, 비유한·비양수 상자, 실제 경계를 벗어난 상자는 거부합니다. 전체 원문 감사에서 pLitter79,101개 및 Plast5,300개 상자의 경계 위반은 0개였습니다(evidence/bbox-audit.json). 여러 객체를 묶은 pile과 개별 쓰레기가 함께 있다는 정의상의 한계를 결과에 남깁니다.

원자료는 work/sources/raw에 보존합니다. 학습 프로세스에는 RGB JPEG quality95/subsampling0 사본만 전달합니다. 원본 해독 후 픽셀을 회전하지 않고 EXIF를 제거합니다. 주석의 width/height와 저장 픽셀의 크기가 일치해야 하며 EXIF 방향을 근거로 상자나 픽셀을 임의 회전하지 않습니다. 원본 SHA, 정규화 SHA, 크기, 방향 metadata, 변환 버전을 이미지별로 대응합니다. 사본 JPEG의 마지막 바이트 FF D9를 검사해 기존 Ultralytics 자동 재저장 원인을 예방합니다. 원본·사본·라벨 해시는 동결한 뒤 변경 값으로 갱신하지 않습니다.

## 누출 방지와 한계

64비트 DCT 지각 해시의 Hamming 거리4 이하, 동일 원본 SHA, 촬영 그룹을 순서에 관계없는 전이적 연결 요소로 합칩니다. 평가와 학습 사이에 연결이 있으면 평가가 우선합니다. 과거 사용 사진과 연결된 새 평가 후보는 제외합니다. 동일 바이트의 train 사본도 하나만 남깁니다. train 내부의 비슷한 연속 프레임은 같은 그룹 안에 유지하므로 개별 사진 수와 독립 그룹 수를 혼동하지 않습니다.

기존 pLitterStreet 사용 ID의 합집합은 5,196개(과거1,999 + 5차3,839 - 중복642)이며, 양성 이미지 미사용 ID는 7,577개였습니다. 전체 7개 장소 모두 과거에 사용됐으므로 새로운 지역 독립 테스트라고 부르지 않습니다. 새 manifest에서는 복원 ID와 새 ID, 정확 중복, 근접 그룹을 따로 집계합니다. 사진·crop·반복 학습 노출도 구분합니다.

PlastOPol의 원문 filename은 수집 ID이며 촬영 위치·연속성을 보증하는 정보가 없습니다. 공식 test와 fold1 validation을 기준으로 시작하고 근접 연결이 경계를 넘으면 test가 val보다, val이 train보다 우선합니다. 이 평가는 새 사진과 근접 중복을 통제한 평가이며 지역·촬영 세션 독립성을 검증했다고 주장하지 않습니다. 검증/test 각각100장 이상, 연결 그룹3개 이상을 요구합니다.

UAVVaste 전체는 학습과 검증에서 보지 않는 새 출처 테스트입니다. 기존 모든 확인 가능한 자료와 정확·지각 해시를 대조합니다. 다만 과거 unofficial 1,232장의 실파일이 없어 이들은 SHA 및 남은 출처 정보만 보존할 수 있습니다. 모든 과거 사진에 대한 절대적인 근접 중복 부재는 확인할 수 없습니다. 항공 시점 테스트 수치를 CCTV 성능으로 해석하지 않습니다. 새 UAV 테스트가 누출 검사 뒤100장보다 작으면 준비를 중단합니다.

과거 TACO test150은 이미 여러 차수에서 평가한 historical benchmark입니다. 모델·신뢰도·타일 설정은 TACO val에서만 선택하고 test150 결과를 다시 튜닝에 쓰지 않습니다. 테스트 전 선택 계약을 고정하며 중단 후에는 같은 계약과 이미지별 예측 캐시로 남은 평가만 이어갑니다.

## 학습·선택·실행

기존 선택 baseline을 같은 정규화·추론 조건에서 다시 검증합니다. 새 후보는 보존 COCO YOLO26l의 960px/batch4, 최대60epoch와 보존 l-P2의 1280px/batch2, 최대45epoch 두 개입니다. 각 후보의 학습 루프 시간은 누적6시간, patience12입니다. Ultralytics time이 epochs를 덮어쓰므로 별도 on_train_epoch_end callback에서 epoch 상한도 적용합니다. 시간 제한은 배치·검증 경계에서 확인되며 완료 후 최종 검증·checkpoint 저장 시간은 추가될 수 있습니다. 다운로드·변환·독립 평가 시간까지 하루 내 완료한다고 보장하지 않습니다.

모든 유효 train 원본을 보존하되 출처가 작은 TACO/PlastOPol을 최대4회 반복해 pLitter 비중을 줄입니다. 원본과 반복 노출 수를 따로 기록합니다. 작은 객체 crop은 train에서만 생성하고 부모ID·split·사각형을 기록합니다. 한 원본에서 최대1개, 전체 train 원본 수의 최대10%를 출처별로 나눕니다. 경계에서90% 미만만 남는 상자나2px 미만 객체가 생기면 그 crop 자체를 제외합니다. 비어 있는 crop을 새 음성 자료로 만들지 않습니다. crop을 평가에 사용하지 않습니다.

검증은 full1280과 full+3×3 겹침 타일(한 이미지·모델당 최대10회 예측)을 비교합니다. TACO val의 min(P,R), F1, 같은 TACO 신뢰도를 적용한 PlastOPol val의 min(P,R), AP50 순으로 선택하며 완전 동점은 기존 모델이 우선합니다. 신뢰도는 TACO val에서만 선택합니다. 입력1280에서의 작은/중간/큰 상자별 P/R, 출처별 P/R, 음성 이미지 수와 음성 이미지당 오탐을 보고합니다. 음성 이미지가0장이면 해당 오탐률은 null이며 음성 성능을 검증했다고 쓰지 않습니다.

AP는 단일 클래스 신뢰도 순 일대일 IoU 매칭의101점 보간 자체 계산입니다. 공식 COCO API AP 또는 Ultralytics val 수치와 같다고 표시하지 않습니다. IoU.5에서 과거 TACO150의 P/R 각각.90이 주목표이고 PlastOPol 및 UAV 결과도 별도 공개합니다. 한 출처의 쉬운 수치만으로 전체90% 달성을 주장하지 않으며 미달 값을 숨기지 않습니다.

worker.run → train_pipeline.run(job, notify=..., resume=False) → prepare_dataset.prepare(notify=...) → 두 후보 학습 → val 선택 → 세 고정 테스트의 순서입니다. 실제 준비/학습은 동일 Docker2026/Linux에서 독립 프로세스로 실행합니다. 중단 checkpoint는 명시적 resume=True와 manifest·코드·원본모델·설정 계약 일치가 필요합니다. 완료 결과가 있으면 원본·가중치 계약을 검사한 뒤 재사용하고 자동 재학습하지 않습니다.

신규 전송은 수신 본문 누적100GiB 상한이고 부분 실패도 합산합니다. 사전 수신 도구는 별도 ledger를 쓰며 동일 images.zip.receiving.lock의 Linux flock을 잡은 채 최종 영수증을 남깁니다. 제품 준비는 잠금 해제 후 공식 크기·MD5·SHA를 재검사하고 최종 ledger를 정확히 한 번 합산합니다. 개별 범위 요청4MiB와40초 제한, 부분 파일·원본 ID 일치를 이용해 재개합니다. ZIP/정규화/crop/학습 checkpoint 예측 쓰기 전 최소100GiB 잔여를 검사합니다. 별도 프로젝트가 동시에 디스크를 쓰는 상황까지 원자적으로 예약하는 운영체제 보장은 아닙니다. GPU 여유 VRAM18,000MiB가 부족하면 최대2시간 기다린 뒤 상태와 원인을 남기며 다른 GPU 프로세스를 중단하지 않습니다.

## 검증 명령

정식 검사는 실제root에서 `python -B -X utf8 -m unittest discover -s tests -v`와 `python -B -X utf8 verify_sources.py`입니다. 각각60초, 합계120초로 부모가 등록한 명세를 사용합니다. 실제 데이터 한 장 검사는 `docker exec -w "/workspace/2026/월요일 PBL/7차" 2026 /opt/venvs/torch/bin/python -B -X utf8 prepare_dataset.py --smoke`입니다. 이는 기존 TACO 원본·라벨과 새 정규화 사본을 검사하며 네트워크 수신이나 GPU 학습은 하지 않습니다. 장기 원자료 수신과 학습 시작은 부모의 독립 검증 뒤 worker에서 수행합니다.
