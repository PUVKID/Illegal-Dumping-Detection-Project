7차 대규모 자료 준비·학습 독립 실행

이 폴더의 학습실행.bat은 Docker 2026 컨테이너의 기존 GPU Python을 사용합니다.
Codex 채팅, API 키, Codex 토큰은 필요하지 않습니다. Docker Desktop과 PC는 켜져 있어야 합니다.
다른 GPU 작업을 중단하지 않으며 GPU가 이미 사용 중이면 자원 오류가 발생할 수 있습니다.

처음 실행: 학습실행.bat
오류 원인·데이터 및 checkpoint 계약을 확인한 뒤 명시적으로 재개: 학습실행.bat resume
상태 확인: 학습상태.bat

실행 요청은 독립 프로세스를 만들고 반환합니다. 자료 다운로드와 검증이 완료되면 학습으로 이어집니다.
준비·학습 전체에 하나의 실행 잠금을 유지하여 동시에 중복 실행하지 않습니다.
자료 해시나 학습 재개 계약이 맞지 않으면 기존 오류를 남기고 중단합니다. 기준을 자동 변경하지 않습니다.
창과 Codex를 닫아도 독립 프로세스는 계속됩니다. PC·Docker가 꺼지면 계산도 멈춥니다.
재개 옵션은 계약 검사를 건너뛰는 옵션이 아닙니다. 완료 여부와 checkpoint 재사용은 파이프라인이 검증합니다.

work/status.json: 가장 최근 작업의 상태
work/jobs/<작업ID>.json: 개별 상태, 오류, traceback, 실행 PID
work/jobs/<작업ID>.log: 작업의 전체 표준 출력과 오류
work/학습상태.html: 마지막 저장 상태를 읽는 정적 화면

상태 HTML은 별도 웹 서버가 아니며 15초마다 파일을 다시 읽습니다.
작업이 강제로 종료되면 HTML은 마지막 기록으로 남을 수 있으므로 학습상태.bat을 실행해 실제 PID 생존 상태를 갱신하세요.
PID와 실제 worker 명령행·작업 ID가 함께 일치해야 실행 중이라고 판단합니다.
기존 1~6차 모델과 데이터를 변경하지 않으며 테스트 지표로 모델을 튜닝하지 않습니다.
정밀도·재현율 각각 90%는 목표입니다. 작업 시작·다운로드 완료만으로 달성했다고 표시하지 않습니다.
이 안내와 실행 파일은 장기 학습이 실제 시작됐다는 증거가 아닙니다. 실제 상태와 로그를 확인하세요.
