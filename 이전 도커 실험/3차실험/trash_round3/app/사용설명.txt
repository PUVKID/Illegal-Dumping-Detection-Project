클린뷰 2차

실행: CleanView.exe를 더블클릭합니다. Docker Desktop과 2026-2 컨테이너가 필요합니다.
별도의 Windows Python 설치는 필요하지 않습니다. 웹 화면은 이 PC에서만 열립니다.

1. 저장된 영상을 고르거나 새 영상을 가져옵니다.
2. '이 영상 탐지하기'를 누릅니다. 세부 설정은 필요할 때만 펼칩니다.
3. '탐지 기록'에서 의심 장면과 결과 영상을 확인합니다.
4. '학습 현황'에서 현재 학습과 최종 성능을 확인합니다.

학습 중에는 탐지가 잠깐 비활성화됩니다. 앱을 닫아도 Docker 학습은 계속됩니다.
2차 학습이 끝나면 검증에서 선택한 모델과 신뢰도, 확대 탐지 설정이 자동 적용됩니다.
정밀도와 재현율 목표는 각각 90% 이상입니다. 달성 여부는 최종 평가로 확인합니다.
정답이 없는 CCTV 영상에는 정확도를 표시하지 않습니다. 쓰레기 물체 검출 성능과
실제 투기 행동을 찾아내는 성능은 다릅니다. 이 앱은 행동을 확정하지 않고 의심 장면을 기록합니다.

2차 실험
- 1차 쓰레기 모델을 이어 학습하지 않습니다. COCO 일반 사물 사전학습에서 새로 시작합니다.
- YOLOv8m과 작은 물체용 YOLOv8m-P2를 각각 최대 180 epochs 학습합니다.
- 검증 성능 개선이 35 epochs 동안 없으면 정상 조기 종료합니다.
- 기존 학습 1,200장 + SALSA/OpenLitterMap 1,243장 + 학습 사진 확대 1,690장.
- 검증 150장 / 테스트 150장은 원래 파일과 라벨을 SHA-256으로 고정했습니다.
- SALSA의 TACO 파생 사진을 제외하고 pHash로 추가 중복도 검사했습니다.
- 일반 탐지/분할 탐지 및 신뢰도는 검증셋에서 고르고, 테스트는 최종 선택 후 한 번 평가합니다.
- 1차 모델도 검증 비교에만 포함하여 2차 후보가 나쁘면 기존 모델을 유지합니다.
