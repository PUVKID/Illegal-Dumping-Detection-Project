# 공개 차수와 비교

비교는 공개 저장소의 각 하위 폴더를 상대 경로로 맞춘 실제 바이트 기준이며 용도가 다른 자료 사이의 차이는 성능 변화를 뜻하지 않습니다. 데이터·실행 상태 등 민감 가능 자료는 원문을 비교 패치에 복제하지 않고 크기와 해시로 표시합니다. 6차는 5차 전체가 아닌 변경 전 일부 파일을 보존합니다. 7차 비교는 아래 문서에 적힌 기준 커밋 시점입니다.
