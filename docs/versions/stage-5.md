입력 — 3차의 고정 테스트 150장 결과와 검증에서 선택한 ensemble/full 정책

처리 — 고정 신뢰도0.17·IoU0.50의 정밀도/재현율과 전체 신뢰도 곡선의 mAP 정리

출력 — 3차_최종보고서.html·최종성능.csv·학습/테스트/탐지 그림

4. 학습에 사용한 추가 자료·중복 검사·고정 시험과 실제 CCTV의 한계를 확인합니다.

### LEVEL 1 · 결과와 주의할 범위

정밀도·재현율은 검증에서 고른 고정 신뢰도에서 다시 매칭한 값이고 mAP는 전체 신뢰도 곡선으로 계산합니다. 원본 해상도 평가이므로 이전 축소 입력과 같은 조건의 개선률로 비교하지 않습니다.

**상황:** HTML의 그림이 표시되지 않음

**확인할 내용:** 성능보고서 폴더의 상대 경로와 PNG 파일을 함께 유지합니다.

**상황:** 정밀도와 mAP의 차이

**확인할 내용:** 고정 신뢰도에서의 정밀도·재현율과 전체 신뢰도 곡선의 mAP를 구분합니다.
