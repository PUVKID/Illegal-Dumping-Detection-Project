<a name="️-화면과-사용-흐름"></a>
## 화면과 사용 흐름

1. 성능보고서/3차_최종보고서.html을 브라우저로 엽니다.
2. 최종성능.csv의 비율·퍼센트·평가조건 열을 함께 읽습니다.
3. 검증임계값·테스트곡선·탐지개수·학습곡선 그림을 보고서 문맥과 대조합니다.
4. 학습에 사용한 추가 자료·중복 검사·고정 시험과 실제 CCTV의 한계를 확인합니다.

<a name="-처리-결과와-출력-읽기"></a>
## 처리 결과와 출력 읽기

정밀도·재현율은 검증에서 고른 고정 신뢰도에서 다시 매칭한 값이고 mAP는 전체 신뢰도 곡선으로 계산합니다. 원본 해상도 평가이므로 이전 축소 입력과 같은 조건의 개선률로 비교하지 않습니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

| 상황 | 확인할 내용 |
|---|---|
| HTML의 그림이 표시되지 않음 | 성능보고서 폴더의 상대 경로와 PNG 파일을 함께 유지합니다. |
| 정밀도와 mAP의 차이 | 고정 신뢰도에서의 정밀도·재현율과 전체 신뢰도 곡선의 mAP를 구분합니다. |
