### LEVEL 1 · 실제 동작을 따라 읽기

확정 시안을 참조해 다운로드·데이터 준비·GPU 학습·검증·최종 평가를 실제 Three.js WebGL 메시와 단계별 움직임으로 구현했습니다. 현재 작업과 다음 단계, 활성·완료·실패·재시도·대기를 문구와 색상으로 함께 구분합니다. 영상 탐지·성능 분석·작업 기록, 나눔고딕 Bold와 기존 접근 제한을 유지합니다.

현재 파일의 진행률은 전체 실험 진행률이 아닙니다. 속도·남은 시간은 유효 표본이 있을 때만 표시하고 최종 평가 전 성능은 미측정으로 남깁니다. 시안의 예시 날짜와 숫자는 실험값으로 사용하지 않습니다. 단계 선택은 설명을 바꾸며 학습이나 탐지를 시작하지 않습니다.

두 비교 문서의 전체 패치는 텍스트의 주석·공백·개행을 포함하고, 바이너리는 크기와 SHA-256으로 구분합니다. 공개 소스·검사·설명·시안·로컬 의존 자산과 라이선스 38개를 포함합니다. 첫 화면과 전체 차수·파일 비교 목차를 연결하며, 기존 공개 자료 정리 안내와 원문 제외 상태를 보존합니다.

Python 검사 52개·JavaScript 검사 21개와 소스 검사를 통과했습니다. Windows 공유 읽기 검사와 원자적 교체 재현, 실화면 대조·재생/정지·작은 화면·영상 기능의 구체적인 범위는 [화면 검증](../../10차/design-qa.md)에 기록했습니다. 초기 잘못된 영역 캡처는 무효 기록을 보존했습니다.

현재 작업의 5단계를 실제 WebGL 모형과 상태 문구·색으로 표시합니다. 정지·재생과 모션 축소, 작은 화면의 접근을 지원합니다.

CLI는 명령어와 옵션을 입력해 프로그램을 실행하는 방식입니다.

입력 — 7차 작업의 상태·진행·결과 기록

처리 — 원본 계약 확인 → 상태 읽기 → 대시보드 상태·단계 표시

출력 — 작업 진행·완료·대기·오류 화면

#### LEVEL 1 · 실행과 표시 조건

Windows에서 `대시보드실행.bat`을 사용합니다. 같은 프로젝트의 5차 영상 실행 자료와 7차 작업 자료, Docker 환경과 필요한 모델·데이터가 별도로 필요합니다. 공개 저장소만 복제하여 전체 실험이 자동으로 재현되는 것은 아닙니다. 기존 8차의 로컬 서버 및 접근 제한을 재사용하며 접속 세션 값은 공개하지 않습니다.

애니메이션은 초당 최대 30프레임과 화면 배율 상한을 두고, 탭 숨김·운영체제의 움직임 줄이기 설정·사용자 정지를 존중합니다. WebGL을 사용할 수 없거나 그래픽 문맥이 끊겨도 텍스트 상태와 단계 정보를 유지하도록 구성합니다. 나눔고딕 Bold, Three.js 0.180.0, Lucide 0.468.0은 로컬 파일과 각각의 라이선스를 함께 보관합니다. 출처와 해시는 `docs/`의 각 명세를 확인하세요.

Windows의 상태 파일 읽기는 삭제 공유를 허용하도록 구성해 원자적 교체와 충돌하지 않도록 했습니다. 8차 원본을 수정하지 않고 10차에서 읽기 함수를 연결합니다. 과거 권한 오류의 책임 프로세스는 확정하지 않았습니다.

### LEVEL 1 · 결과와 주의할 범위

화면에서 읽은 상태와 실제 학습 성능을 구분합니다. 3D 단계나 진행률은 작업 상태의 표현이며 90% 정확도 달성값이 아닙니다.

**상황:** 학습 또는 화면이 시작되지 않음

**확인할 내용:** 해당 차수 환경·모델·데이터·설정 경로를 확인합니다. 화면 전용 차수는 학습 코드의 대체물이 아닙니다.

**상황:** 원본 계약 검사 실패

**확인할 내용:** 원래 코드·설정·자료 해시를 대조합니다. 현재 해시로 기준을 바꿔 우회하지 않습니다.

**상황:** 지표 해석이 어려움

**확인할 내용:** 검증으로 선택한 정책과 고정 테스트, 기존 시험과 새 출처 외부 시험을 구분합니다.

### 실행과 표시 조건

Windows에서 `대시보드실행.bat`을 사용합니다. 같은 프로젝트의 5차 영상 실행 자료와 7차 작업 자료, Docker 환경과 필요한 모델·데이터가 별도로 필요합니다. 공개 저장소만 복제하여 전체 실험이 자동으로 재현되는 것은 아닙니다. 기존 8차의 로컬 서버 및 접근 제한을 재사용하며 접속 세션 값은 공개하지 않습니다.

애니메이션은 초당 최대 30프레임과 화면 배율 상한을 두고, 탭 숨김·운영체제의 움직임 줄이기 설정·사용자 정지를 존중합니다. WebGL을 사용할 수 없거나 그래픽 문맥이 끊겨도 텍스트 상태와 단계 정보를 유지하도록 구성합니다. 나눔고딕 Bold, Three.js 0.180.0, Lucide 0.468.0은 로컬 파일과 각각의 라이선스를 함께 보관합니다. 출처와 해시는 `docs/`의 각 명세를 확인하세요.

Windows의 상태 파일 읽기는 삭제 공유를 허용하도록 구성해 원자적 교체와 충돌하지 않도록 했습니다. 8차 원본을 수정하지 않고 10차에서 읽기 함수를 연결합니다. 과거 권한 오류의 책임 프로세스는 확정하지 않았습니다.

<a name="-처리-결과와-출력-읽기"></a>
## 처리 결과와 출력 읽기

화면에서 읽은 상태와 실제 학습 성능을 구분합니다. 3D 단계나 진행률은 작업 상태의 표현이며 90% 정확도 달성값이 아닙니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

**상황:** 학습 또는 화면이 시작되지 않음

**확인할 내용:** 해당 차수 환경·모델·데이터·설정 경로를 확인합니다. 화면 전용 차수는 학습 코드의 대체물이 아닙니다.

**상황:** 원본 계약 검사 실패

**확인할 내용:** 원래 코드·설정·자료 해시를 대조합니다. 현재 해시로 기준을 바꿔 우회하지 않습니다.

**상황:** 지표 해석이 어려움

**확인할 내용:** 검증으로 선택한 정책과 고정 테스트, 기존 시험과 새 출처 외부 시험을 구분합니다.
