## LEVEL 1 - Beginner

### LEVEL 1 · 이 자료가 하는 일과 달라진 점

최종 앙상블의 단일 프레임 표시와 문서 PDF 렌더 작업을 보관합니다.

### LEVEL 1 · 실제 동작을 따라 읽기

최종 앙상블의 단일 프레임 표시와 문서 PDF 렌더 작업을 보관합니다.

3차 모델의 출력과 문서를 설명 자료로 정리한 단계입니다.

- make_frame은 selected_model의 ensemble/policy/conf로 첫 영상 프레임을 예측하고 사람 상단 영역에 블러를 적용한 설명 PNG를 만듭니다. - 그림에는 단일 프레임 기능 확인·투기 사건 판정 결과 아님을 명시하고 test_metrics_recomputed를 False로 기록합니다. - render_with_word는 문서 렌더러의 PDF 변환을 Word 호출로 연결합니다. 학습이나 테스트 지표 계산 코드가 아닙니다.

3차 모델의 단일 프레임 결과와 문서를 정리했습니다.



입력 — 고정 컨테이너의 첫 MP4 프레임·selected_model.json·기존 가중치

처리 — 앙상블 쓰레기 탐지와 사람 검출 → 상단40% 블러 → PNG/JSON 기록

출력 — 단일 프레임 그림과 프레임_확인.json

### LEVEL 1 · 준비하고 확인할 것

make_frame.py는 원래 Docker 컨테이너2026-2와 /root/환경 PBL/trash_round3를 고정 참조합니다. 기존 모델·동영상·글꼴과 Docker 환경 없이 독립 실행되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

1. 실제 자료 구성에서 필요한 원문 파일을 엽니다.
2. 고유 설명에 적힌 입력 조건·경로·대상을 확인합니다.
3. 연결된 비교와 기록의 관측 범위를 대조합니다.

### LEVEL 1 · 결과와 주의할 범위

test_metrics_recomputed=False로 시험 지표를 재계산하지 않습니다. 한 프레임의 객체 상자는 투기 사건 판정 성적이 아닙니다.

| 상황 | 확인할 내용 |
|---|---|
| 실행 자료가 부족함 | 이 묶음의 보존 범위와 원래 참조 차수를 확인합니다. |
| 결과 범위 해석 | 자료 열람·기능 확인·실험 성적을 각각 구분합니다. |
