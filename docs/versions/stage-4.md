## 🎯 목적과 이 차수의 역할

최종 앙상블의 단일 프레임 표시와 문서 PDF 렌더 작업을 보관합니다.

<a name="features"></a>

## ✨ 핵심 기능과 보존 범위

| 항목 | 이 차수에서 확인할 내용 |
|---|---|
| 1 | 최종 앙상블의 단일 프레임 표시와 문서 PDF 렌더 작업을 보관합니다. |
| 2 | 3차 모델의 출력과 문서를 설명 자료로 정리한 단계입니다. |
| 3 | - make_frame은 selected_model의 ensemble/policy/conf로 첫 영상 프레임을 예측하고 사람 상단 영역에 블러를 적용한 설명 PNG를 만듭니다. - 그림에는 단일 프레임 기능 확인·투기 사건 판정 결과 아님을 명시하고 test_metrics_recomputed를 False로 기록합니다. - render_with_word는 문서 렌더러의 PDF 변환을 Word 호출로 연결합니다. 학습이나 테스트 지표 계산 코드가 아닙니다. |
| 4 | 3차 모델의 단일 프레임 결과와 문서를 정리했습니다. |

## 🔄 입력·처리·출력

| 단계 | 내용 |
|---|---|
| 📥 입력 | 고정 컨테이너의 첫 MP4 프레임·selected_model.json·기존 가중치 |
| ⚙️ 처리 | 앙상블 쓰레기 탐지와 사람 검출 → 상단40% 블러 → PNG/JSON 기록 |
| 📤 출력 | 단일 프레임 그림과 프레임_확인.json |
