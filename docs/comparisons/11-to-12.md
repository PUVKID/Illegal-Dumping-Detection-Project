# 11차 → 12차 공개 폴더 전체 비교

11차는 기존 실험의 자료 수신을 복구하는 도구이고 12차는 실험 종료 후 보고서를 작성하는 별도 소프트웨어입니다. 상대 경로와 실제 바이트를 비교합니다. 아래 삭제는 11차 파일을 12차 폴더에 다시 포함하지 않았다는 뜻이며 기존 11차 파일을 저장소에서 삭제한 것이 아닙니다. 이 폴더 비교와 저장소 커밋의 변경 목록은 범위가 다릅니다.

추가 16개, 수정 3개, 삭제 4개, 동일 0개입니다. [전체 텍스트 차이](11-to-12.patch)는 주석과 공백을 포함하며 바이너리는 크기와 SHA-256으로 구분합니다.
