# 10차 → 11차 공개 폴더 전체 비교

10차는 입체 대시보드이고 11차는 고정 7차 파이프라인 앞에 수신 복구를 연결하는 독립 실행기입니다. 두 폴더의 상대 경로와 실제 바이트를 비교합니다. 아래 삭제는 해당 파일을 11차 폴더에 다시 포함하지 않았다는 뜻이며 기존 10차 파일을 프로젝트나 저장소에서 삭제한 것이 아닙니다. 10차 화면은 기존 경로에서 유지합니다.
