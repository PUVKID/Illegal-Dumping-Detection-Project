# 2026-11-02 · 실험 보고서 생성 도구

지정된 기존 실험의 완료 상태와 동결 결과를 대조한 뒤 Word와 동일 원고 PDF를 만드는 12차 소프트웨어 19파일을 추가합니다. 11차는 수신 복구, 12차는 문서 후처리로 목적이 다르며 이전 차수는 보존합니다. [전체 파일 비교](../comparisons/11-to-12.md)의 삭제는 이전 파일을 새 폴더에 재포함하지 않았다는 뜻입니다.

공개 파일의 44개 단위 검사와 합성 시제품의 8쪽 문서 렌더 확인은 제어 사례에 대한 검사입니다. 실제 장기 실험 결과, 모델의 성능이나 목표 달성을 뜻하지 않습니다. 실제 결과가 없거나 실패·중단된 상태를 완료로 해석하지 않습니다. [12차 변경 기록](../../12차/변경기록.md)에 기능과 검사 범위를 기록했습니다.

기존 7차 동결 설치 환경이 필요합니다. 공개 저장소에는 기준 문서 두 개가 없고 검사 파일 하나의 줄바꿈 바이트가 달라 단독 복제본만으로 원본 해시 검사를 통과하지 못할 수 있습니다. 기준 해시를 현재 값으로 바꾸어 우회하지 않으며, 10차 안전 읽기와 글꼴 및 11차 복구 코드의 고정 의존성도 확인합니다.

실제 작성자 설정·최종 보고서·시제품·원본 데이터·모델·실행 기록과 인증정보는 공개 대상에서 제외합니다. 이번 공개 대상은 보고서 생성 소프트웨어와 고정 설명 템플릿이며 새로운 논문 원고 성과가 아닙니다.
