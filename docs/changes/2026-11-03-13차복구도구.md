# 13차 공개 변경 기록

7차의 기존 실험 계획에 보존 이미지 ID 복구와 12차 보고서 연결을 추가했습니다. 원본과 실효 코드 네 변경 지점은 [별도 비교](../comparisons/7-to-13-prepare.patch), 12차와 13차의 모든 공개 파일은 [전체 비교](../comparisons/12-to-13.md)에서 확인합니다. 실제 저장소에는 13차 공개 파일과 설명·비교 자료를 추가하고 차수 목록을 수정했습니다. 기존 차수의 파일은 삭제하지 않았습니다.

Windows 43개 검사 중 Linux 전용 1개 건너뜀, Docker 43개 통과 및 합성 보고서 검사를 확인했습니다. 실제 실험 성과는 측정 결과로만 판정하며 개인 최종 보고서는 이번 공개 범위가 아닙니다.
