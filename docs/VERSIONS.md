- 현재 연구 파일 합계: **93개**. 루트 `README.md`, `CHANGELOG.md`, `.gitignore`와 `docs/` 관리 문서는 집계에서 제외합니다.
- 경로에서 처음 만나는 숫자 차수 또는 `최종`으로 묶습니다. 같은 상위 경로의 숫자 차수끼리만 경로·SHA-256을 비교합니다. `기본`과 `최종`은 독립 묶음이므로 다른 차수와 자동으로 의미 대응시키지 않습니다.
- 추가·변경·이전 경로 수는 파일 비교 결과입니다. 기능 변경은 [README의 구체적인 구현·차수 설명](../README.md)을 함께 확인하세요.
- 제외된 원데이터·모델·인증정보와 관리 문서는 이 표의 대상이 아닙니다.

## ⚖️ 자료별 기능 비교

| 경로 | 확인한 역할 |
|---|---|
| `1차` | 쓰레기 데이터셋 통합·1개 클래스 YOLOv8m 재학습과 영상 평가 노트북 |
| `2차` | 봉투와 낱개 쓰레기 분류를 위한 YOLOv8n 학습 및 영상 처리 노트북 |
| `최종/3차` | 중복 관리 데이터 준비, 학습·검증 선택·고정 테스트와 클린뷰 추론 코드 |
