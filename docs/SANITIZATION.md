# 인증 정보 제거 기록

노트북 2개의 인증 설정을 `ROBOFLOW_API_KEY` 필수 환경변수 참조로 바꿨습니다. 환경변수 값이 없으면 `KeyError`로 설정 이름을 알립니다. 과거 키·프롬프트·입력 안내 문자열은 넣지 않았고 비밀정보 값이나 원문 이력은 공개 저장소에 싣지 않습니다.

- 다른 셀의 원문과 차수 경로를 유지했습니다.
- 노트북 출력·실행 횟수·첨부·위젯 메타데이터를 제거했습니다.
- 원본 SHA-256·사본 SHA-256·문법·필수 환경변수 실패 경로를 별도 검사합니다.
- 설치·학습 명령 등 기존 노트북 매직은 실행하지 않았습니다.
