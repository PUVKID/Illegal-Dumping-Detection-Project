# 🧹 10차 공개 자료 정리

[프로젝트](../../README.md) · [전체 차수](../REVISION_INDEX.md) · [이번 파일별 변경](공개파일변경.json)

7차 실험의 다운로드·데이터 준비·GPU 학습·검증·최종 평가를 움직이는 Three.js 입체 모형과 실제 상태 문구로 연결했습니다. 영상 탐지·성능 분석·작업 기록을 같은 화면에서 확인하고, 움직임 정지·재생과 모션 축소 설정을 반영합니다. 현재 파일의 진행률과 전체 실험 진행을 구분하며 미측정 성능을 확정값으로 표시하지 않습니다.

[10차 자료](../../10차/)에는 소스·검사·실행 설명·시안과 로컬 의존 자산·라이선스 38개를 보관합니다. 9차는 7차 수신 재개를 기록한 운영 문서입니다. [9차 → 10차 전체 비교](../comparisons/9-to-10.md)와 [8차 화면 소스와의 비교](../comparisons/8-to-10.md)에서 주석·공백을 포함한 텍스트 차이와 바이너리 크기·해시를 확인할 수 있습니다.

이번 목차 추가 전에 사용한 [이전 검수 파일별 변경 목록](이전검수파일변경-10차추가전.json)은 같은 원문으로 보존했습니다. 기존 팀 보고서·거래 증빙의 공개 제외를 유지하며, 10차의 원본 데이터·모델·실행 상태·로그·접속 값·개인 지침과 비공개 검증 자료는 포함하지 않습니다. 공개 출처와 의존 자산의 법적 저자명·라이선스는 보존합니다.

10차는 새 논문 원고가 없는 화면 소프트웨어 작업입니다. 학습 완료나 정밀도·재현율 각각 90% 달성을 뜻하지 않으며, 실행 환경과 실제 화면 확인 범위는 [10차 안내](../../10차/README.md)와 [화면 검증 기록](../../10차/design-qa.md)에 있습니다.
