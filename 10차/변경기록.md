# 📝 10차 공개 변경 기록

## 2026-11-02 · 3D 대시보드와 상태 표시

- 확정된 1513×1040 시안을 참고해 실험 현황과 영상 탐지·성능 분석·작업 기록 화면을 구성했습니다. 시안의 예시 날짜·숫자는 실제 데이터로 사용하지 않습니다.
- 다운로드·데이터 준비·GPU 학습·검증·최종 평가를 Three.js 입체 메시와 단계별 동작으로 표현하고 실제 상태에 따른 색상을 구분합니다. 선택 동작은 학습을 시작하지 않습니다.
- 파일 단위 진행과 전체 실험 진행을 구분하고 실제 관측 표본이 부족한 속도·남은 시간과 최종 평가 전 성능은 확정값으로 표시하지 않습니다.
- 화면 접근 제한과 기존 영상·7차 상태 연결을 보존하고, Windows 상태 파일의 공유 읽기를 10차에서 적용해 원자적 교체 충돌을 방지하도록 했습니다. 7차·8차 원본 코드는 수정하지 않았습니다.
- 시안·나눔고딕 Bold·Three.js·Lucide 자산과 해당 라이선스 및 출처를 포함합니다. 브라우저 동작과 검사 결과는 별도 확인 기록과 함께 해석합니다.
- 초기 시각 대조에서 발견된 시점·크기·형태 차이, 상태 파일 공유 문제, 과거 오류 안내 잔존, 조명 표본 경고와 큐브 이동 방향 오류를 수리했습니다. 관측과 수정 내용은 [설계 이력](docs/설계.md)에 보존합니다. 과거 권한 오류의 책임 프로세스는 확정하지 않았습니다.
- [9차와 전체 파일 비교](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/docs/comparisons/9-to-10.md), [8차 화면과 전체 파일 비교](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/docs/comparisons/8-to-10.md)에는 추가·수정·삭제, 텍스트의 주석·공백 및 바이너리 크기·해시를 표시합니다.
- Python 52개·JavaScript 21개·소스 검사를 통과했습니다. Windows 공유 읽기 검사 14개와 제어된 원자적 교체 500회·읽기 40,446회를 확인했습니다. 실화면과 시안을 대조하고 모바일 넘침·재생/정지 프레임·영상 기능을 확인한 범위는 [화면 검증](design-qa.md)에 기록했습니다. 초기 잘못된 영역 캡처는 무효로 남기고 전체 화면에서 재검사했습니다.
- 각 단계·실패·재시도 화면의 시험용 상태는 인공적으로 만든 검사 자료이며 실제 학습 결과가 아닙니다.
- 2026-11-02 관측 당시 7차는 자료 수신 단계였습니다. 장기 학습 완료와 정밀도·재현율 각각 90% 목표 달성은 확인되지 않았습니다.
- 원본 데이터·모델·로그·세션·인증정보·개인 지침과 비공개 검증 증거를 제외합니다. 10차는 새 논문 원고가 없는 소프트웨어 작업이며 기존 공개 원고는 변경하지 않습니다.
