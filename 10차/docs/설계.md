# 10차 디자인 및 구현 계약

확인한 시안은 design/대시보드_시안.png입니다. 시안은 흰색 좌측 내비게이션과 흰 카드, 넓은 민트색 무대, 청록·에메랄드 활성 상태로 구성됩니다. 제목은 크게, 현재 파일 수치는 오른쪽에서 한눈에 읽히도록 배치합니다. 시안의 예시 날짜·숫자는 제품에 복사하지 않습니다.

디자인 시스템: 글꼴 NanumGothic Bold 700, 바탕 #f6faf9, 흰 카드 #ffffff, 본문 #142c30, 보조 #708781, 경계 #e1ece8, 민트 #e7f8f0, 에메랄드 #07966b. 왼쪽 탐색 210px, 본문 최대 1600px, 본문 여백 36px, 카드 모서리 20px, 카드 간격 20px, 제목 32px/현재 작업 30px/본문 14px. 1100px 이하에서는 상태 카드를 아래로 내리고 720px 이하에서는 탐색을 가로로 전환합니다.

고정 문구: ‘실험 현황’, ‘영상 탐지’, ‘성능 분석’, ‘작업 기록’. 다섯 단계는 ‘다운로드’, ‘데이터 준비’, ‘GPU 학습’, ‘검증’, ‘최종 평가’입니다. ‘현재 파일 기준 · 전체 실험 진행률이 아닙니다’, ‘프로세스 생존은 별도 확인이 필요합니다’, ‘최종 평가 전에는 성능을 표시하지 않습니다’로 의미를 구분합니다. 상태 제목과 설명은 실제 작업 단계·실패·재시도·자료 유무에 따라 결정합니다.

3D 무대는 실제 Three.js WebGL 메시로 클라우드·낙하 큐브·이미지 스택·팬과 회로를 갖춘 GPU·돋보기·리포트를 구성합니다. 재질·부품·입체 받침·연결 통로·부드러운 그림자와 직교 카메라를 사용합니다. 시안 이미지를 화면 배경으로 대체하지 않습니다. 문구와 수치는 모두 DOM이며 3D는 단계 선택 설명만 제공합니다. 단계 선택은 어떤 학습·탐지도 시작하지 않습니다.

성능: DPR 최대 1.5, 애니메이션 최대 30fps, 탭 숨김 정지, 운영체제 모션 축소 존중, 명시적 정지 버튼. WebGL 불가나 contextlost에서도 DOM 단계·상태·기능을 유지하고 오류를 표시합니다. 원격 CDN을 사용하지 않습니다. Three.js 0.180.0 원본 URL·라이선스·해시는 docs/vendor-manifest.json에 기록합니다.

기존 8차 상태·서버 보안·5차 영상 경로 검증·7차 worker 중복 잠금을 재사용합니다. 새 10차 상태는 표시 정보만 보강합니다. 파일 진행률은 downloaded_bytes/file_bytes이며 GiB 단위를 명시하고 전체 실험 퍼센트로 표현하지 않습니다. 속도·ETA는 같은 작업·소스·파일의 서로 다른 저장 시각 두 개로 측정할 때만 표시하고 파일·재시작 변경 시 초기화합니다. 준비 단계에서는 GPU 학습 대기, 에포크 —입니다. 실제 곡선과 최종 지표만 표시합니다.

성공 조건: 이전 23개 회귀 이식, 단계·상태·파일 진행률·자료 없음·재시도·오래된 자료·실패·학습·검증·완료의 표시 검사, JS 형식·속도 표본 초기화 검사, WebGL 모듈 인증·의존 해시 검사. 실제 서버와 브라우저 화면·영상·내비게이션·3D 정지·콘솔 검사는 부모 독립 검증에서 수행합니다. 실행 중인 7차 작업과 기존 8차 서버를 중단하지 않습니다.

## 확정 시안 충실도 보완

사용자가 2026-11-02 ‘보낸 이미지대로 완전 똑같게’, ‘실제로 움직이게’, ‘색 변환 단계별’을 명시했습니다. 기존 디자인 토큰의 기본 회색 바탕과 작은 제목 해석보다 확정 시안을 우선해 본문을 #ffffff, 탐색을 옅은 민트 #f5fbf9로 맞춥니다. 1513px 화면에서는 탐색 210px·본문 여백 24px·제목 40px·현재 작업 제목 36px·오른쪽 카드 320px·입체 캔버스 360px를 기준으로 시안과 대조합니다. 브랜드는 시안 잎 모양을 참조해 생성한 제공 PNG를 사용하고, 메뉴·새로고침·성능·기록 아이콘은 Lucide 0.468.0의 MIT 원본 SVG를 로컬 제공하며 해시·출처를 별도 기록합니다.

다운로드에서만 큐브 낙하와 초록 연결 흐름, 데이터 준비에서만 사진 정렬, GPU 학습에서만 팬 회전과 회로 빛, 검증에서만 돋보기 이동, 최종 평가에서만 리포트 체크 동작이 표시됩니다. 실패·중단은 코랄, 재시도는 호박색, 완료는 민트, 대기는 회색입니다. 수동 선택은 테두리와 설명만 바꾸며 실제 단계 색과 작업을 변경하지 않습니다.

## 실화면 대조 수리 2

1513×1040 실화면과 확정 시안 대조에서 작은 글꼴·과한 조명·반대 방향 시점·각진 수평 받침·상자형 단계 버튼을 확인했습니다. 시안의 검은 44px 현재 제목·20px 부제·22px 현재 파일·62px 비율·18px 탐색·13px 표에 맞추며 수평 받침은 XZ 평면의 둥근 외곽으로 변경합니다. 실제 무대는 반대 방향 직교 시점과 확대된 부품, 낮춘 조명 및 런타임 스튜디오 환경 반사를 사용합니다. 사진은 얕게 돌출된 산 모양으로 고칩니다. 단계는 짧은 알약 버튼·연결선·작은 원 표시를 따릅니다. GPU 여유 메모리 확인은 자원 대기이며 에포크를 표시하거나 팬을 돌리지 않습니다. 준비 후 자동 GPU 시작 안내와 다운로드 검증·데이터 준비 문구를 사용합니다.

## 상태 파일 공유 읽기와 자료 없음 표시 수리 3

별도 deep 담당자의 Windows·Docker 통제 재현에서 일반 읽기 핸들이 상태 JSON 원자 교체를 방해하는 충분조건을 확인했습니다. 과거 오류 순간의 책임 PID는 확정하지 않습니다. 새 safe_io.py의 삭제 공유 읽기를 10차에 로드한 8차 모듈 전역 read에 연결하여 8차 원본을 보존합니다. 10차 실행 세션과 검사 manifest 읽기도 같은 엄격 읽기를 사용하며 JSON·UTF-8 오류는 숨기지 않습니다. 자료가 없으면 다음 단계는 작업 대기/기록 없음입니다. 실패 화면은 자료 보존과 작업 기록 확인을 간결하게 알리고 원문 오류는 작업 기록과 상태 원문에 보존합니다.

### 이전 서버 유지 계약의 실제 운영 예외

초기 계약의 기존 8차 서버 유지와 달리, 일반 Windows 읽기 핸들이 Docker 상태 JSON의 원자적 교체를 방해하는 충분조건을 통제 재현으로 확인했습니다. 새 10차 서비스의 정상 응답을 확인한 뒤 기존 8차 서버의 명령과 경로를 대조해 종료했습니다. 이는 8차 원본 코드를 변경한 것이 아니며 실행 중인 7차 worker를 직접 중단한 것도 아닙니다. 과거 worker 실패 뒤 이미 허용된 재개는 별도로 진행했습니다. 과거 오류 순간의 책임 프로세스는 확정하지 않았습니다.

## 회복 상태 메시지와 활성 색 수리 5

실패 뒤 새 정상 다운로드 전환에서 과거 실패 안내가 남는 오류를 실제 화면에서 확인했습니다. 상태 오류와 사용자 동작·네트워크 안내를 구분하고 정상 전환 시 상태 오류만 지웁니다. 활성 입체 부품은 채도가 유지되는 초록 #00c84f 재질, 흰 트레이 외곽·초록 테두리·투명 연결부·점광으로 시안에 맞춥니다. 학습·검증·평가처럼 준비 이후임이 확인된 실제 단계에서만 이전 단계가 완료 민트로 변합니다. 초기 포괄적 준비 문구에서는 과거 완료를 추정하지 않습니다. 모든 strong·b도 700으로 고정하고 deep 검사 파일을 필수 배포 목록에 포함합니다.

## PMREM 표본 상한과 에포크·다음 단계 안내 수리 6

공식 r180 PMREM은 기본 큐브 크기 256, 최대 표본 20입니다. 원래 sigma 0.08은 39개 표본을 요구해 잘림 경고가 발생했습니다. 소스의 실제 계산식과 상한을 확인해 sigma 0.04의 20개 표본으로 수정하며 벤더나 경고를 숨기지 않습니다. Node 검사는 고정 벤더의 크기·표준편차·상한과 실제 장면 설정을 대조합니다. 분석 탭도 표시 어댑터의 epoch만 사용해 GPU 자원 대기에서 이전 후보의 원문 epoch를 표시하지 않습니다. 다음 단계의 부제도 현재 단계별 실제 안내로 바꾸고 실패·자료 없음·GPU 자원 대기를 구분합니다.

수리 6 추가 실제 모션 대조: 기존 큐브 수식은 시간이 늘수록 높이가 커져 상승하는 오류였습니다. 높이가 줄어들고 끝에서 위로 재생성하는 함수로 바꾸고 시간순 좌표를 검사합니다. 실패·재시도 알약 버튼의 글자·원 표시·연결선도 각 코랄·호박색으로 통일합니다. 이전 상승 모션 오류의 관측 이력은 지우지 않습니다.

수리 6 마지막 브라우저 회귀 범위: 390px 화면의 카드 최소 내용 폭 때문에 문서가 480px로 넘치는 오류를 확인했습니다. 카드와 열은 min-width 0/minmax(0,1fr)로 줄어들고 표만 내부 가로 스크롤하도록 수정합니다. 모션 축소 설정의 초기값과 동적 변경은 공통 상태 통지로 재생 버튼의 문구·aria-pressed까지 동기화합니다. 실제 운영체제 설정은 변경하지 않습니다. 이 범위 이후 모형 구조·운영 작업은 추가 수정하지 않습니다.
