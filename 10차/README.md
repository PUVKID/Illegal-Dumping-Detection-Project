# 🧹 10차 · 입체 실험 대시보드

[설계와 수리 이력](docs/설계.md) · [화면 검증](design-qa.md) · [공개 변경 기록](변경기록.md) · [디자인 시안](design/대시보드_시안.png)

7차 실험의 현재 상태를 확인하고 영상 탐지·성능 분석·작업 기록으로 이동하는 대시보드입니다. [8차 대시보드](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/tree/main/8차)를 바탕으로 화면을 다시 구성하며, 7차 학습 코드와 8차 원본을 보존합니다.

## 🧭 현재 작업을 한눈에 확인

다운로드, 데이터 준비, GPU 학습, 검증, 최종 평가의 다섯 단계를 Three.js WebGL 입체 장면으로 표현합니다. 실제 상태에 따라 활성·완료·실패·재시도·대기 색상을 구분하며 단계별 움직임을 사용합니다. 단계 선택은 설명을 바꾸는 동작이며 학습이나 탐지를 시작하지 않습니다.

상태와 수치는 실제 상태 자료에서 읽습니다. 시안에 들어 있는 예시 날짜와 숫자는 실측값으로 사용하지 않습니다. 다운로드 진행률은 **현재 파일 기준**이며 전체 실험 진행률이 아닙니다. 속도와 남은 시간은 유효한 관측 표본이 있을 때만 표시합니다. 프로세스 생존은 별도 확인이 필요하고, 최종 평가 전의 성능은 미측정입니다.

[시안](design/대시보드_시안.png)은 화면 구성의 디자인 참고 이미지이며 그 안의 예시 숫자는 실제 실험 데이터가 아닙니다. 실제 제품은 정지 이미지를 배경으로 쓰지 않고 WebGL 메시를 그립니다. 좁은 화면에서는 배치가 달라집니다.

## 🖥️ 실행과 표시 조건

Windows에서 `대시보드실행.bat`을 사용합니다. 같은 프로젝트의 5차 영상 실행 자료와 7차 작업 자료, Docker 환경과 필요한 모델·데이터가 별도로 필요합니다. 공개 저장소만 복제하여 전체 실험이 자동으로 재현되는 것은 아닙니다. 기존 8차의 로컬 서버 및 접근 제한을 재사용하며 접속 세션 값은 공개하지 않습니다.

애니메이션은 초당 최대 30프레임과 화면 배율 상한을 두고, 탭 숨김·운영체제의 움직임 줄이기 설정·사용자 정지를 존중합니다. WebGL을 사용할 수 없거나 그래픽 문맥이 끊겨도 텍스트 상태와 단계 정보를 유지하도록 구성합니다. 나눔고딕 Bold, Three.js 0.180.0, Lucide 0.468.0은 로컬 파일과 각각의 라이선스를 함께 보관합니다. 출처와 해시는 `docs/`의 각 명세를 확인하세요.

Windows의 상태 파일 읽기는 삭제 공유를 허용하도록 구성해 원자적 교체와 충돌하지 않도록 했습니다. 8차 원본을 수정하지 않고 10차에서 읽기 함수를 연결합니다. 과거 권한 오류의 책임 프로세스는 확정하지 않았습니다.

## ✅ 확인한 범위

Python 검사 52개, JavaScript 검사 21개와 소스 검사를 통과했습니다. 별도 Windows 공유 읽기 검사 14개와 제어된 원자적 교체 500회·공유 읽기 40,446회 검사를 수행했습니다. 이는 정해진 조건에서의 검사이며 과거 실패의 책임 프로세스를 입증하지 않습니다.

같은 뷰포트에서 시안과 실화면의 구조를 대조하고, 전체 화면의 같은 영역에서 재생 중 프레임 변화와 정지 후 동일함을 확인했습니다. 초기 일부 영역 캡처가 잘못된 위치를 반환해 그 비교를 무효로 기록한 뒤 재검사했습니다. 390px 모바일 뷰포트에서 재검사한 문서 너비는 375px였습니다. 실제 영상 미리보기와 보관된 결과 재생은 기능 검사이며 새 실험 성능을 뜻하지 않습니다. 자세한 범위와 픽셀 일치의 한계는 [화면 검증](design-qa.md)에 있습니다.

## 📚 비교와 해석

[9차 운영 기록과 10차 전체 비교](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/docs/comparisons/9-to-10.md) · [8차 화면 소스와 10차 비교](https://github.com/PUVKID/Illegal-Dumping-Detection-Project/blob/main/docs/comparisons/8-to-10.md)

9차는 7차 재개를 기록한 문서이며 10차는 화면 소프트웨어입니다. 서로 다른 폴더의 추가·삭제는 기존 차수 파일의 실제 삭제를 뜻하지 않습니다. 기존 고정 테스트 및 새 외부 테스트의 의미는 7차 실험 계약에 따릅니다. 현재 실험이 진행 중이라는 표시를 학습 완료나 정밀도·재현율 90% 달성으로 해석하지 않습니다.

원본 데이터·모델·실행 로그·작업 상태·접속 토큰·개인 지침과 검증용 비공개 증거는 공개 자료에 넣지 않습니다. 이번 차수는 소프트웨어 작업이며 새 논문 원고는 없습니다. 기존 원고에 대한 별도 검토를 대신하지 않습니다.
