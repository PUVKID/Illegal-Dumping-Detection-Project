# 10차 디자인·동작 확인

확인일: 2026-11-02. 기준은 사용자가 선택한 `design/대시보드_시안.png`(1513×1040)입니다. 시안의 예시 날짜·비율은 실제 값으로 복사하지 않습니다. 아래 증거 식별자는 로컬 비공개 검증 파일이며 공개 다운로드 링크가 아닙니다.

## 비교 기준

- 좌측 민트 탐색, 흰 본문, 큰 현재 작업 제목, 다섯 입체 단계, 우측 현재 파일·GPU·다음 단계, 하단 성능·작업 표를 같은 순서로 대조합니다.
- 나눔고딕 Bold 700을 제목·본문·버튼·수치에 적용합니다. 시안의 장식용 창 테두리는 실제 브라우저 안에 중복 구현하지 않습니다.
- 시안은 생성된 정지 이미지이며 제품은 실제 WebGL 메시입니다. 재질·곡면·그림자까지 픽셀이 동일하다는 주장은 하지 않습니다. 화면 배치와 다섯 모형의 대응을 유지하면서 움직임과 실제 상태 연결을 구현합니다.
- 색은 활성 초록, 증거가 있는 이전 완료 단계 민트, 대기 회색, 실패 코랄, 재시도 호박색으로 구분합니다. 성능 미측정과 실제 진행 상태를 디자인보다 우선합니다.

## 반복 확인과 발견 사항

1. 최초 동일 크기 비교에서 작은 글꼴, 반대 시점, 각진 받침과 사진 부품을 확인해 수정했습니다. 증거: `cua-native-1.jpg`.
2. 실제 실패 뒤 새 정상 작업으로 전환해도 과거 오류 안내가 남는 문제를 확인하고 수정했습니다. 증거: `cua-native-3-live.jpg`, 수리 후 `cua-native-5-live-ready.jpg`.
3. 검증용 인공 상태를 실제 실험과 분리해 다운로드·준비·학습·검증·평가·실패·재시도·완료 화면을 확인했습니다. 모든 인공 상태 화면에 ‘검증용 합성 상태 · 실제 실험 아님’을 표시합니다. 증거: `phase-download.jpg`, `phase-prepare.jpg`, `phase-train.jpg`, `phase-validation.jpg`, `phase-test.jpg`, `phase-failed.jpg`, `phase-retry.jpg`, `phase-complete.jpg`.
4. 390×844에서 성능·최근 작업 카드가 가로로 넘치는 문제, 다음 단계 부제의 고정 문구, 실패 단계 표시의 초록색 잔존을 발견했습니다. 증거: `mobile-overview.jpg`. 수리 6에서 수정하고 동일한 390×844 화면에서 다시 확인했습니다. 수리 후 문서 너비 375px로 화면 너비 390px를 넘지 않습니다. 증거: `mobile-overview-repair6.jpg`.
5. 독립 검토에서 큐브 상승 방향, 동적 모션 축소 설정과 버튼 동기화, 분석 탭의 누적 에포크 표시를 발견했습니다. 환경맵 흐림의 표본 한도 경고와 함께 수리 6에 포함했습니다.

## 기능 확인 범위

실제 보관 영상 선택과 미리보기, 기존 결과 영상 재생을 확인했습니다. 새 GPU 탐지·추가 학습을 검사 목적으로 중복 시작하지 않습니다. 기존 결과 영상은 기능 검사이며 진행 중인 실험의 성능 증거가 아닙니다. 4GB 업로드 전체 용량 시험은 수행하지 않았습니다.

움직임 정지·재생 버튼과 단계별 제목·현재 단계 전환을 브라우저에서 확인했습니다. 분석·작업 기록·영상 탐지 탭은 390px에서 가로 넘침이 없었습니다. 수리 후 반응형 배치와 실제 모션 프레임을 다음 절에서 확정합니다.

## 최종 판정

**브라우저 디자인·동작 확인 통과** — 승인된 화면 수준과 구조를 기준으로 확인했습니다. 독립 소스 검증과 공개 반영은 별도 기록에서 확인합니다.

- 최종 실화면 `final-native-live.jpg`와 기준 PNG를 같은 1513×1040 뷰포트에서 함께 열어(실화면 캡처 파일은 도구 출력 기준 1498×1030) 배치·글꼴·색·모형 대응·문구를 대조했습니다. 좌측 탐색, 현재 제목, 다섯 모형, 우측 파일 상태, 하단 두 카드의 구조를 유지합니다. 실측 날짜와 파일 수신 비율, 실제 실패 이력은 예시 대신 현재 자료를 표시합니다.
- 초기 영역 캡처가 일부 프레임에서 잘못된 위치를 반환해 초기 비교를 무효로 분류하고 원문을 보존했습니다. 전체 화면 캡처를 실제 크기로 환산한 같은 캔버스 영역을 다시 대조했습니다. `motion-frame-analysis-final.json`에서 재생 중에는 구름·낙하 큐브 영역의 픽셀이 달랐고, 정지 후에는 동일했습니다. 정지·재생 버튼의 문구와 눌림 상태도 확인했습니다. 큐브 하강 방향과 모션 축소 변경 동기화는 좌표·이벤트 회귀 검사로 확인하며 운영체제 설정을 직접 변경하지 않았습니다.
- GPU 자원 대기에서 모형과 단계 글자·원·연결선의 회색을 확인했습니다. 우측 에포크와 분석 탭의 누적 에포크가 숨겨지고, 팬이 학습 동작을 하지 않는 상태를 유지합니다. 수리 7에서 모형만 회색이 된 중간 누락과 수리 8의 DOM 수정 이력은 보존합니다. 증거: `gpu-wait-final-dom.json`, `phase-gpu-wait-repair8.jpg`.
- 자료 없음은 작업 대기·미측정, 오래된 자료는 갱신 지연·프로세스 생존 별도 확인으로 표시합니다. 정상 회복 시 예전 실패 안내가 없어지는 것도 확인했습니다. 단계 선택은 설명만 바꿉니다. 실제 작업이 진행 중일 때 추가 학습 버튼이 비활성인 것을 확인했습니다.
- 최종 서버에서 확인한 브라우저 콘솔 경고·오류는 0개입니다. 이전 환경맵 표본 경고는 지우거나 숨기지 않고 지원 범위의 흐림값으로 수정했습니다. 증거: `final-browser-console.json`.
- 한계: 생성 시안의 세부 곡면·반사·조명과 실제 메시의 픽셀 일치는 보장하지 않습니다. 모형과 표현은 실제 움직이는 입체 구현으로 대응하며 현재 디자인 수준은 사용자 확인을 받았습니다. WebGL 문맥 손실·초기 실패, 동적 모션 축소는 코드·회귀 검사 범위이며 브라우저에서 그래픽 연결을 강제로 끊거나 운영체제 설정을 바꾸지는 않았습니다. 실제 학습 완료나 성능 90% 달성을 뜻하지 않습니다.
